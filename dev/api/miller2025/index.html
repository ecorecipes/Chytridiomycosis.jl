Refugia CTMC (Miller et al. 2025)

This is a reference implementation of the continuous-time Markov chain of Miller et al. (2025, arXiv:2503.06846 v3, not peer reviewed). It models Bd in outdoor mesocosms of the green and golden bell frog Litoria aurea, given either shaded or sunlight-heated ("unshaded") refugia. It was checked against the paper and the authors' R code (Zenodo 10.5281/zenodo.15179344). Time is in weeks, and states are frog counts per mesocosm.

The model

There are eight states:

  • S_U, I_U1, I_U2, I_U3: frogs with no prior infection;
  • S_V, I_V1, I_V2, I_V3: frogs that have recovered from an infection ("vaccinated").

In environment h, a naive susceptible frog is infected at rate β_h F/(N − 1), where F = Σ m_kj I_kj weights each infected state by its relative infectiousness. A vaccinated susceptible frog is infected at rate α β_h F/(N − 1).

  • Infected frogs move I_k1 → I_k2 → I_k3 at rates γ1 = 1/2.5 and γ2 = 1/4.5 per week.
  • They recover to S_V at rate ω.
  • Frogs leave every state at the loss rate μ.

Each mesocosm starts with (S_U, I_U1, S_V, I_V1) = (5, 5, 5, 5) and is surveyed in weeks 0, 1, 2, 4, 6, 8, 10 and 15. The simulator follows the authors' GillespieSSA code exactly:

  • the 0/0 propensity at N = 1 is set to zero;
  • each survey reads the state at that week.
Chytridiomycosis.RefugiaParameters — Type
RefugiaParameters(; β_sh, β_un, α, ω, μ, γ1, γ2, m)
RefugiaParameters(:miller2025; set = "", kwargs...)

Parameters of the Miller et al. (2025) refugia CTMC, as rates per week:

  • β_sh, β_un: transmissibility with shaded and with sunlight-heated ("unshaded") refugia;
  • α: susceptibility of previously infected ("vaccinated") frogs relative to naive frogs;
  • ω: recovery rate from I_k,3 to S_V;
  • μ: loss rate (death or not found) from every state;
  • γ1, γ2: progression rates I_k,1 → I_k,2 → I_k,3;
  • m: infectiousness of (I_U1, I_U2, I_U3, I_V1, I_V2, I_V3) relative to I_U3.

The compendium constructor reads every value from data/compendium/miller2025.toml. The base set holds the fixed constants (Table S1) and the posterior means of Table 3. The set "synthetic" holds the Table S2 values used for Supplement S2. Keyword arguments override single values, for example RefugiaParameters(:miller2025; β_sh = 0.5).

Chytridiomycosis.RefugiaCTMCProblem — Type
RefugiaCTMCProblem(p; environment = :shaded, u0 = refugia_initial_state(),
                   tspan = (0.0, T_f), saveat = refugia_observation_weeks())

The Miller et al. (2025) CTMC for one mesocosm in one environment. Defaults:

  • T_f = 15 weeks, from the compendium;
  • saveat is the survey weeks of the data: 0, 1, 2, 4, 6, 8, 10 and 15.

solve(prob; rng) simulates the chain exactly with the direct method (Gillespie). It returns (; t, u, events):

  • t is saveat;
  • u is an 8 × length(t) matrix of counts. Column k is the state at t[k].
  • events is the number of transitions.

With trajectory = true it also returns jump_times and jump_states, every transition.

Chytridiomycosis.RefugiaODEProblem — Type
RefugiaODEProblem(p; environment = :shaded, u0 = refugia_initial_state(),
                  tspan = (0.0, T_f))

The deterministic version of the refugia model (Supplement S3, eqs S1–S8). It has the CTMC's rates, with N(t) the sum of the eight states. The authors fitted it by least squares to obtain the synthetic-data parameters (Table S2). solve(prob; saveat, kwargs...) integrates with Tsit5 and returns the ODESolution; to_ode_problem(prob) gives the ODEProblem. The force of infection is set to zero when N(t) ≤ 1, as in the CTMC.

ABC rejection

The paper's ABC fixes μ from Eq. (3) and draws (β_sh, β_un, α, ω) from uniform priors.

  1. For each draw it simulates one shaded and one unshaded mesocosm.
  2. It scores the draw by the squared differences from every observed mesocosm in the same environment (Eq. 2).
  3. It accepts the best 0.2% of 10⁶ draws.

A run takes a few seconds on four threads.

The paper's priors (Table 3) differ from those in the Zenodo code:

Table 3Zenodo code
β_sh, β_unU(0, 2)U(0, 1)
ωU(0, 2)U(0, 10)

RefugiaPrior provides both.

Chytridiomycosis.RefugiaPrior — Type
RefugiaPrior(; β_max, α_max, ω_max, μ_max = nothing)
RefugiaPrior(:miller2025; set = "")

Independent uniform priors β_sh, β_un ~ U(0, β_max), α ~ U(0, α_max) and ω ~ U(0, ω_max). With μ_max === nothing the loss rate is fixed, as in the paper. A number makes it μ ~ U(0, μ_max) too, as in the coded generate_priors before the code overwrites μ. That case is used for the μ–ω identifiability check.

The compendium constructor gives the paper's priors (Table 3). set = "code_priors" gives the priors in the authors' Zenodo code.

Chytridiomycosis.refugia_distance — Function
refugia_distance(data, sim_shaded, sim_unshaded; include_t0 = true)
    -> (; shaded, unshaded, total)

The ABC summary statistic of Miller et al. (2025), Eq. (2). Each simulation is an 8 × weeks matrix of counts at data.weeks, for example solve(prob).u. Each is compared with every mesocosm of its own environment, and the squared differences are summed. With include_t0 = true week 0 is included, as in the authors' calc_summary_stats.R.

Chytridiomycosis.refugia_abc — Function
refugia_abc(data = load_miller2025(); prior = RefugiaPrior(:miller2025),
            μ = parameter_set(:miller2025).μ, nsamples = 10^6, acceptance = 0.002,
            seed = 47, chunk = 10_000, include_t0 = true, base = RefugiaParameters(:miller2025))

ABC rejection as in Miller et al. (2025) §2.3. It runs on Threads.nthreads() threads, and the result does not depend on the number of threads.

  1. Draw nsamples parameter sets from prior.
  2. For each, simulate one shaded and one unshaded mesocosm with RefugiaCTMCProblem dynamics (fixed constants from base, loss rate μ unless the prior varies it).
  3. Score each by refugia_distance against data.
  4. Accept the round(acceptance × nsamples) smallest. Ties are broken by draw order, as R's order does.

Each block of chunk draws has its own Xoshiro stream, seeded from seed and the block number.

Returns (; names, accepted, distance, threshold, nsamples):

  • accepted is an naccept × 5 matrix with columns names = (:β_sh, :β_un, :α, :ω, :μ);
  • distance is the accepted draws' statistics.

See refugia_abc_summary.

source
Chytridiomycosis.refugia_abc_summary — Function
refugia_abc_summary(res) -> NamedTuple

Posterior summaries of an ABC result from refugia_abc, laid out like Table 3 of Miller et al. (2025). For each of β_sh, β_un, α, αβ_sh, αβ_un, ω and μ, it gives (; mean, median, lo, hi), where lo and hi are the 2.5% and 97.5% quantiles (R's default type 7).

It also gives the effects of §3.2, which are ratios of posterior means:

  • refugia_effect = 1 − mean(β_un)/mean(β_sh) (Eq. 5);
  • vaccination_effect_sh = 1 − mean(αβ_sh)/mean(β_sh) and vaccination_effect_un likewise (Eq. 4).

Reproduction status

scripts/miller2025_vs_R.jl (with its R driver scripts/miller2025_vs_R.R) compares 10,000 runs of this simulator with 10,000 runs of the authors' R code at three parameter sets. scripts/miller2025_abc.jl repeats the ABC and the identifiability checks. Its output is stored in data/miller2025/abc_reproduction.toml, which is our reproduction and not a published result.

Against the authors' R code

We compared 10,000 runs per environment at each of three parameter sets: the Table 3 means, the Table S2 values, and a high-transmission set.

  • Mean counts. 313 state × week × environment comparisons. The z statistics have mean −0.04 and sd 0.97, and the largest |z| is 3.5. Rerunning that case with 160,000 Julia runs gives |z| ≈ 2.
  • Distributions. 1 of 313 Kolmogorov–Smirnov tests has p < 0.01, against 3 expected by chance.
  • ABC summary statistic. For the total statistic, KS p is 0.53, 0.03 and 0.78 for the three sets. At the Table 3 means, the mean total is 3372 in R and 3367 in Julia.

Every Table 3 value lies within 3 sd of our mean. The code's priors do not give Table 3: they give β_sh 0.33 and ω 1.79. So the published run used the priors stated in the paper.

In our run, the posterior probability that β_un < β_sh is 0.74, and the posterior median of β_un/β_sh is 0.50.

Identifiability

  • α and β. The posterior SD of αβ_sh is 0.08 of its prior SD. For α the ratio is 0.64 and for β_sh it is 0.98, and log α and log β_sh have correlation −0.70.
    • In a simulation–estimation study with 20 data sets at the Table S2 values, the 95% intervals of β span 84–97% of the prior's. That of αβ_sh spans 7%.
    • All intervals cover the truth. The posterior mean of αβ_sh is still about 60% above the truth.
  • Loss and recovery. With the loss rate free, μ ~ U(0, 1), μ is estimated above Eq. (3): posterior mean 0.06 per week, against 0.021. ω stays close to its prior. The posterior correlation of μ and ω is weak (0.15).
