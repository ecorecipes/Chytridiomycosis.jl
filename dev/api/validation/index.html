Validation targets

The registry in data/validation/targets.toml lists the published numbers and outcomes that the implementations must reproduce. Each target has:

  • the paper and the place in it;
  • the package call that reproduces it;
  • a tolerance;
  • a status: reproduced, qualitative, discrepant (the paper's number is not reproduced, and our value is recorded as a regression check) or pending (no implementation yet).

The test suite runs every target that is not pending.

for t in validation_targets(; status = :discrepant)
    println(t.id, ": paper ", t.published, ", we get ", check_target(t).value)
end
Chytridiomycosis.ValidationTarget — Type
ValidationTarget

One published reproduction target, read from data/validation/targets.toml. Fields:

  • id, model (the wiki model page or model name), source (a references.tsv key) and location (where in the paper);
  • quantity and published, the value or outcome the paper reports;
  • call, the package code that reproduces it, evaluated in the package module;
  • tolerance, a Dict with one of digits (equal after rounding), atol, rtol, or lower and upper (strict interval); an empty Dict means exact equality;
  • status: one of
    • :reproduced: the published number is matched within tolerance;
    • :qualitative: a published statement is matched as a condition;
    • :discrepant: the paper's number is not reproduced; regression holds ours;
    • :pending: no implementation yet;
  • regression, our value and its tolerance as a Dict, or nothing;
  • notes.

See validation_targets and check_target.

reproduce(t::ValidationTarget)

Run the target's call in the package module and return what it computes. A :pending target has no call and throws an ArgumentError.

source
Chytridiomycosis.check_target — Function
check_target(t::ValidationTarget) -> (; value, published, regression)

Reproduce target t and compare the result.

  • published is true when the value matches the paper within t.tolerance.
  • regression is true when it matches our recorded value, and nothing when there is no regression value.

For a :discrepant target published is expected to be false.
