Fitting to field data

New analysis

The load equation and these fits are new work in this package, not a published analysis. The data are from Knapp et al. (2022), CC BY 4.0.

The frog load equation dL/dt = ι + r0 L − s(t) L/(h + L) fitted by maximum likelihood to the Dusy Basin 2012 skin swabs of Knapp et al. (2022) (doi:10.7717/peerj.12712). Four mechanisms for the extra clearance s(t) are compared. A KnappLoadModel implements the LogDensityProblems interface (logdensity, dimension, capabilities), so it can also be passed to LogDensityProblems-based samplers. See the tutorial Fitting the frog load model to a field trial, and Bayesian fit to field data for priors, NUTS and PSIS-LOO.

KnappSwab(day, group, bd, jl)

One skin swab from Knapp et al. 2022: day relative to 19 July 2012 (the first J. lividum bath), group (:treated, :control or :wild), Bd load bd (ITS copies per swab) and Janthinobacterium lividum jl (genomic equivalents per swab); NaN when not measured.

Model and fitting

Chytridiomycosis.KnappLoadModel — Type
KnappLoadModel(mechanism = :bacteria; swabs = load_knapp2022(),
    p = BriggsParameters(:briggs2010), dt = 0.05)

Likelihood of the Knapp et al. 2022 swabs under the frog load equation dL/dt = ι + r0 L − s(t) L/(h + L) (loads in ITS copies per swab, time in days), with r0 = ηνf − σ from p. mechanism sets the extra clearance s(t):

  • :none: none.
  • :decay: treated frogs only, Δc exp(−t/τ).
  • :applied: treated frogs only, Δc J/(J + K), with J the J. lividum on treated frogs.
  • :bacteria: every group, Δc J/(J + K) with its own J. lividum.

The model implements the LogDensityProblems interface: the log density is the log-likelihood of the parameters on the log scale (a flat prior), in the order of parameter_names. Fit it with maximum_likelihood, or add a prior with KnappPosterior for a Bayesian fit. dt is the step of the exponential integrator.

source
Chytridiomycosis.parameter_names — Function
parameter_names(m::KnappLoadModel)

Names of the parameters, all fitted on the log scale:

  • ι: infection from outside the frog (copies per swab per day);
  • L0: load of treated frogs on day 0;
  • σ: standard deviation of log Bd load;
  • aT, aW, aC: J. lividum on day 12 on treated, wild and control frogs (genomic equivalents);
  • hT, hW: its half-life (days) on treated frogs and on wild and control frogs;
  • σJ: standard deviation of log J. lividum;
  • Δc, h: the most extra clearance (copies per day) and the load at which it halves;
  • τ (:decay): the time scale of waning (days);
  • K (:applied, :bacteria): J. lividum giving half the extra clearance.

Chytridiomycosis.predicted_loads — Function
predicted_loads(m::KnappLoadModel, x; days = [-7, 0, 12, 37, 56])

Chytridiomycosis.maximum_likelihood — Function
maximum_likelihood(m::KnappLoadModel; starts = 8, iters = 2000, spread = 1.0,
    x0 = knapp_start(m), rng = Random.Xoshiro(1))

Maximum likelihood fit by Nelder–Mead on the log parameters, restarted from x0 and from starts − 1 points drawn around it (normal, standard deviation spread; draws where the likelihood cannot be evaluated are redrawn). Each start is polished by a second, smaller simplex. Returns a NamedTuple: model, x (log parameters), estimates (natural scale, by name), loglik, aic, and logliks (best of each start, to check agreement).

source
maximum_likelihood(model::RumschlagModel; starts = 4, iters = 3000, spread = 0.3,
    rng = Random.Xoshiro(1))

Maximum likelihood fit of a RumschlagModel, by Nelder–Mead on the log parameters. It starts from a default point and from starts − 1 points drawn around it (normal, standard deviation spread), and polishes each start with a smaller simplex.

Returns a NamedTuple:

  • model and x (the log parameters);
  • estimates, the natural-scale parameters by name;
  • loglik, df (number of parameters) and aicc, with n = nobs(model);
  • logliks, the best value from each start, to check that the starts agree.

The lifespans of the paper are 24/m hours (zoospore_lifespan). Use rumschlag_parameters to get each water's parameters.

source
maximum_likelihood(m::SurveyModel; starts = 3, rounds = 3, iters = 2000, spread = 1.0,
    x0 = log of the starting values, rng = Random.Xoshiro(1))

Maximum likelihood fit of a SurveyModel by Nelder–Mead on the log parameters, as for the Knapp fit but preconditioned: the simplex moves in coordinates whitened by the expected_information (one unit = one standard error along each of its eigenvectors), recomputed at the current best point for each of rounds. Without this the simplex stalls in the narrow curved ridges of this likelihood. Restarts from x0 and from starts − 1 points spread standard errors around it. Returns a NamedTuple model, x, estimates (natural scale, by name), loglik, aic and logliks (best of each start).

source
maximum_likelihood(model::TomprosModel; starts = 6, iters = 1500, rng = Random.Xoshiro(1))

Maximum likelihood fit of a TomprosModel by Nelder–Mead on the log parameters. The first start is a default point; the others are drawn as in the authors' CodeFile3_Optimisation.R (rates and κ's uniform on 0.1–2 times the default, exponents uniform on 0.5–1.5). Each start is polished by a second, smaller simplex. Parameters are held at or above model.lower.

Returns a NamedTuple with model, x (log parameters), estimates (natural scale, by name; values at the lower bound are reported as model.lower), nll (negative log-likelihood), k, aic = 2 nll + 2k and nlls (best value from each start).

Chytridiomycosis.profile_likelihood — Function
profile_likelihood(fit, name::Symbol, values; iters = 1500)

Profile log-likelihood of parameter name at each of values (natural scale), for a result of maximum_likelihood: the other parameters are re-optimised at each value, moving outward from the estimate. Returns a vector of log-likelihoods. Values within about 1.92 of fit.loglik form an approximate 95% confidence interval.

source
profile_likelihood(m::SurveyModel, name::Symbol, values; x0 = log of the starting values,
    kwargs...)

Profile log-likelihood of parameter name of a SurveyModel at each of values (natural scale): the model is refitted by maximum_likelihood (keywords passed on) with name fixed at each value and the other free parameters re-estimated, starting from x0 (pass fit.x of the full fit). Values within 1.92 of the maximum log-likelihood form an approximate 95% confidence interval.
