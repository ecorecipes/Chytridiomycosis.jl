Fitting to field data

New analysis

The load equation and these fits are new work in this package, not a published analysis. The data are from Knapp et al. (2022), CC BY 4.0.

The frog load equation dL/dt = ι + r0 L − s(t) L/(h + L) fitted by maximum likelihood to the Dusy Basin 2012 skin swabs of Knapp et al. (2022) (doi:10.7717/peerj.12712). Four mechanisms for the extra clearance s(t) are compared. A KnappLoadModel implements the LogDensityProblems interface (logdensity, dimension, capabilities), so it can also be passed to LogDensityProblems-based samplers. See the tutorial Fitting the frog load model to a field trial.

Data

Chytridiomycosis.KnappSwab — Type
KnappSwab(day, group, bd, jl)

One skin swab from Knapp et al. 2022: day relative to 19 July 2012 (the first J. lividum bath), group (:treated, :control or :wild), Bd load bd (ITS copies per swab) and Janthinobacterium lividum jl (genomic equivalents per swab); NaN when not measured.

load_knapp2022(path = knapp2022_path()) -> Vector{KnappSwab}

Read the Dusy Basin 2012 swabs of Knapp et al. 2022 (doi:10.7717/peerj.12712). Days are counted from 19 July 2012, the first J. lividum bath: treated frogs received itraconazole on days −7 to −1.

Model and fitting

Chytridiomycosis.KnappLoadModel — Type
KnappLoadModel(mechanism = :bacteria; swabs = load_knapp2022(),
    p = BriggsParameters(:briggs2010), dt = 0.05)

Likelihood of the Knapp et al. 2022 swabs under the frog load equation dL/dt = ι + r0 L − s(t) L/(h + L) (loads in ITS copies per swab, time in days), with r0 = ηνf − σ from p. mechanism sets the extra clearance s(t):

  • :none: none.
  • :decay: treated frogs only, Δc exp(−t/τ).
  • :applied: treated frogs only, Δc J/(J + K), with J the J. lividum on treated frogs.
  • :bacteria: every group, Δc J/(J + K) with its own J. lividum.

The model implements the LogDensityProblems interface: the log density is the log-likelihood of the parameters on the log scale (a flat prior), in the order of parameter_names. Fit it with maximum_likelihood. dt is the step of the exponential integrator.

source
Chytridiomycosis.parameter_names — Function
parameter_names(m::KnappLoadModel)

Names of the parameters, all fitted on the log scale:

  • ι: infection from outside the frog (copies per swab per day);
  • L0: load of treated frogs on day 0;
  • σ: standard deviation of log Bd load;
  • aT, aW, aC: J. lividum on day 12 on treated, wild and control frogs (genomic equivalents);
  • hT, hW: its half-life (days) on treated frogs and on wild and control frogs;
  • σJ: standard deviation of log J. lividum;
  • Δc, h: the most extra clearance (copies per day) and the load at which it halves;
  • τ (:decay): the time scale of waning (days);
  • K (:applied, :bacteria): J. lividum giving half the extra clearance.

knapp_start(m::KnappLoadModel)

Default starting point (log scale) for maximum_likelihood.

Chytridiomycosis.predicted_loads — Function
predicted_loads(m::KnappLoadModel, x; days = [-7, 0, 12, 37, 56])

Median Bd load (ITS copies per swab) and J. lividum (genomic equivalents) predicted for each group on days (sorted), at log parameters x. Returns a NamedTuple with fields days and treated, wild, control, each a NamedTuple of vectors bd and jl. Treated frogs before day 0 are at their untreated equilibrium; their J. lividum is reported as 0 before day 0.

source
Chytridiomycosis.maximum_likelihood — Function
maximum_likelihood(m::KnappLoadModel; starts = 8, iters = 2000, spread = 1.0,
    x0 = knapp_start(m), rng = Random.Xoshiro(1))

Maximum likelihood fit by Nelder–Mead on the log parameters, restarted from x0 and from starts − 1 points drawn around it (normal, standard deviation spread; draws where the likelihood cannot be evaluated are redrawn). Each start is polished by a second, smaller simplex. Returns a NamedTuple: model, x (log parameters), estimates (natural scale, by name), loglik, aic, and logliks (best of each start, to check agreement).

source
Chytridiomycosis.profile_likelihood — Function
profile_likelihood(fit, name::Symbol, values; iters = 1500)

Profile log-likelihood of parameter name at each of values (natural scale), for a result of maximum_likelihood: the other parameters are re-optimised at each value, moving outward from the estimate. Returns a vector of log-likelihoods. Values within about 1.92 of fit.loglik form an approximate 95% confidence interval.
