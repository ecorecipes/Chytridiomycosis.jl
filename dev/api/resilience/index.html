Resilience and thresholds

The resilience machinery is in DynamicalResilience.jl (steady states, R₀ by the next-generation method, Floquet multipliers, following resilience along a parameter) and ResilienceCore.jl (what a linearised operator means and which metrics apply to it). This package only says where its models' equilibria are and which of their terms are new infections. The tutorial Thresholds and resilience uses them on Schmidt's Bsal model and on the load-tipping model.

Chytridiomycosis.equilibrium_state — Function
equilibrium_state(prob, state::Symbol) -> Vector{Float64}

A named equilibrium of a model, as a state vector in the order of its ODE:

problemstates
SchmidtSLIProblem:endemic (eq. 2.3; it exists only above the invasion threshold), :disease_free ([K, 0, 0])
BsalLarvalProblem:disease_free ([K, 0, 0, W*, 0] with W* = disease_free_larvae)
LoadTipping:low_load (the stable low load), :threshold (the unstable load above which load runs away)

Throws an ArgumentError if the model has no such state at its parameters (for example, no endemic state below the invasion threshold, or no low load in the :runaway regime).

source
ResilienceCore.linearise — Method
linearise(prob::SchmidtSLIProblem; state = :endemic)  -> ContinuousJacobian
linearise(prob::BsalLarvalProblem; state = :disease_free) -> ContinuousJacobian
linearise(m::LoadTipping; state = :low_load)          -> ContinuousJacobian

ResilienceCore's linearise at a named equilibrium of a model (see equilibrium_state): the Jacobian of its ODE there, with the equilibrium attached, so that every ResilienceCore metric (resilience, reactivity, …) applies. The Schmidt and load-tipping Jacobians are analytic; the larval model's is computed by automatic differentiation of its right-hand side. Time is in years for the Bsal models and in days for the load model.

source
DynamicalResilience.reproduction_number — Method
reproduction_number(prob::SchmidtSLIProblem)  -> (R0, F, V, K)
reproduction_number(prob::BsalLarvalProblem)  -> (R0, F, V, K)

R₀ by DynamicalResilience's general next-generation method, with the infection structure of each model: for Schmidt's model the infected states are L and I and new infections βSI enter L; with the larval stage they are W_I, L and I, new larval infections λ_W W_S enter W_I and new adult infections βSI + β_AW S W_I enter L (carry-over through metamorphosis is a transition). Equal to basic_reproduction_number, which gives the same quantity in closed form; this method also returns the next-generation matrix K.

source
Chytridiomycosis.to_ode_problem — Method
to_ode_problem(m::LoadTipping; S0 = 0.0, tspan = (0.0, 365.0))

The one-host load equation dS/dt = ι + (λ − σ + κ) S − c S/(h + S) as an out-of-place ODEProblem whose parameters are the LoadTipping model itself. Use it with DynamicalResilience's resilience_along, varying a field with, for example, (m, ι) -> LoadTipping(ι, m.λ, m.σ, m.c, m.h, m.κ).

source

The individual-based seasonal models (for example BriggsStagedProblem) have no ODE to linearise; their resilience is a question for simulation.
