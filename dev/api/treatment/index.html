Microbiome treatment

New models

These models are new work in this package, not published results. Apart from values read from the compendium, treatment parameters are illustrative.

A treated class of hosts carrying protective skin bacteria, put on each host–pathogen model.

The treatment

Chytridiomycosis.MicrobiomeTreatment — Type
MicrobiomeTreatment(; efficacy = 0, half_life = Inf, direct = 0, environmental = 0,
                    reservoir_half_life = 1, tolerance = 0, shedding_reduction = 0,
                    abundance_half_life = Inf, protective_fold = Inf)

A protective microbiome carried by "treated" hosts. efficacy (0–1) is the proportional reduction in the infection rate of a treated host. tolerance (0–1) is the proportional reduction in the disease-induced death of a treated host once infected; such a host stays infectious, shedding 1 − shedding_reduction times as much as an untreated one. (None of these is used by ProbioticLoadProblem, which takes c_treated.) A treated host reverts to untreated with half-life half_life. An untreated host acquires the microbiome at rate direct × (treated fraction of hosts) plus environmental × E, where E is an environmental reservoir with half-life reservoir_half_life. Times and rates are in the host model's time unit.

Waning: the applied bacteria decline with abundance_half_life, and protective_fold is the starting abundance divided by the abundance that gives half the full effect. Efficacy, tolerance and shedding reduction are all multiplied by protection at the time since the last application. With the default abundance_half_life = Inf there is no waning.

Chytridiomycosis.load_reducing_treatment — Function
load_reducing_treatment(load_reduction; death_exponent = 1, kwargs...)

A MicrobiomeTreatment that lowers the pathogen load of a treated, infected host to 1 − load_reduction times the untreated load. Shedding is taken as proportional to load, and disease-induced death as proportional to load raised to death_exponent:

shedding_reduction = load_reduction
tolerance          = 1 − (1 − load_reduction)^death_exponent

death_exponent = 1 is death proportional to load; above 1, death falls off faster than load (as with a lethal load threshold); below 1, more slowly. Other keywords (efficacy, half_life, direct, ...) pass to MicrobiomeTreatment.

source
Chytridiomycosis.protection — Function
protection(t::MicrobiomeTreatment, age)

Fraction of the full treatment effect that remains age after an application. Abundance is B(age) = B₀ 2^(−age/abundance_half_life) and the effect is proportional to B/(B + B₅₀), with B₀/B₅₀ = protective_fold, scaled to 1 at age 0:

protection = (1 + 1/F) / (1 + 2^(age/h)/F)

It falls to about one half after log2(F) abundance half-lives.

protection_duration(t::MicrobiomeTreatment; level = 0.5)

Time after an application at which protection has fallen to level.

Chytridiomycosis.reversion_rate — Function

Rate at which a treated host reverts to untreated, log 2 / half_life.

Chytridiomycosis.microbiome_reproduction_number — Function
microbiome_reproduction_number(t; turnover = 0)

Number of hosts that one treated host passes the microbiome to, in an untreated population, before it loses it or is replaced: (direct + environmental) / (ω + turnover). turnover is the hosts' replacement rate (births of untreated hosts balancing deaths). Above 1 the microbiome maintains itself without further treatment.

source
Chytridiomycosis.equilibrium_coverage — Function
equilibrium_coverage(t; turnover = 0)

Long-run treated fraction in a host population that is always present, with no further treatment: 1 − 1/R where R is microbiome_reproduction_number, or 0 if R ≤ 1. Direct and environmental transmission count equally here; they differ only in timing.

source
Chytridiomycosis.treatment_efficacy — Function
treatment_efficacy(treated, untreated, disease_free)

Share of the disease-induced loss that treatment averts, for any outcome measured in the three situations: (treated − untreated)/(disease_free − untreated).

Chytridiomycosis.mortality_reduction — Function
mortality_reduction(deaths_treated, n_treated, deaths_control, n_control;
                    draws = 20_000, rng)

Proportional reduction in the risk of death in a two-arm challenge trial, 1 − p_treated/p_control, as (median, lower, upper) with a 95% interval. Each arm's risk has a Beta(½, ½) prior. A statistical summary of one trial, not a parameter for another host.

On the host models

Chytridiomycosis.ProbioticSLIProblem — Type
ProbioticSLIProblem(p::SchmidtParameters, treatment; coverage = 0, treat_times = [0.0],
                    t_intro = 0.0, I0 = 0.01, tspan = (0.0, 10.0))

Schmidt et al. (2017) Bsal model with a treated class. The population starts at K. At each of treat_times a fraction coverage of untreated hosts is treated; Bsal (I0 infectious per ha) arrives at t_intro. Time in years.

solve returns series t, hosts, treated, infectious and the summaries min_hosts, mean_hosts and final_hosts after t_intro, as fractions of K, and final_prevalence (the infectious fraction of hosts at the end).

source
Chytridiomycosis.effective_reproduction_number — Function
effective_reproduction_number(p::SchmidtParameters, t::MicrobiomeTreatment, coverage)

Bsal's reproduction number when a fraction coverage of hosts is treated: R₀ (1 − coverage + coverage × m), with m = (1 − efficacy)(1 − shedding_reduction)(b + d_I)/(b + (1 − tolerance) d_I) the transmission from a treated host relative to an untreated one. It ignores gain and loss of the microbiome during an infection. Tolerance makes m larger and a shedding reduction makes it smaller; m > 1 means that treatment raises the reproduction number.

source
Chytridiomycosis.critical_coverage — Function
critical_coverage(p::SchmidtParameters, t::MicrobiomeTreatment)

Treated fraction needed to stop Bsal invading: (1 − 1/R₀)/(1 − m), with m as in effective_reproduction_number. A value above 1 means no coverage is enough; Inf means treatment does not lower the reproduction number at all.

source
critical_coverage(p::BriggsParameters; c, c_treated, h, N, ε = 0)

Smallest treated fraction of N hosts at which a low-load state exists (the population is not in the :runaway regime of the load tipping model). NaN if even full coverage is not enough.

Chytridiomycosis.ProbioticPondProblem — Type
ProbioticPondProblem(p::MitchellParameters, treatment; stage = :tadpoles, coverage = 0,
    treat_years = 0:(years - 1), maternal = 0, adult_seeding = 0, years = 35,
    spinup = 100, Z0 = 1e4, A0 = p.K / 2, toad_limit = 50, bd_limit = 100,
    stages = PostMetamorphicInfection(), redose_days = [])

Mitchell et al. (2008) toad–Bd model with a treated class. In each year of treat_years (year 0 is the year Bd arrives) a fraction coverage is treated: of the newly hatched tadpoles if stage = :tadpoles, or of the adults just before breeding if stage = :adults. Treated adults pass the microbiome on directly (maternal: probability that a treated adult's tadpole is born treated) or through the pond (adult_seeding: reservoir added at breeding when all adults are treated). Time in years.

stages adds infection after metamorphosis (PostMetamorphicInfection): an infected metamorph survives with probability s_J = metamorph_survival, or s_J + tolerance (1 − s_J) if treated, and metamorphs leaving the pond are exposed for metamorph_exposure_days (treated ones at 1 − efficacy times the rate). Untreated adults can be infected while at the pond, as in ToadStageProblem (adult_exposure_days > 0); they are never treated, so this needs stage = :tadpoles. With no treatment the model is then ToadStageProblem.

redose_days (for stage = :tadpoles) are days after hatching at which, in each treatment year, treated tadpoles are dosed again and a fraction coverage of the untreated ones is treated. Each application restarts the waning clock of protection.

Stochastic version: solve(prob; rng) makes every individual tadpole, juvenile, adult and zoospore a whole number. Between events the transitions are drawn in steps of dt years (default one day); births, treatment, survival through metamorphosis and to maturity are binomial or Poisson draws. toad_limit and bd_limit are then not used: toads and Bd go extinct when their numbers reach zero. The reservoir E stays continuous.

solve returns series at each event (t, A, A_treated, Z, tadpoles_treated as a fraction of uninfected tadpoles), and toads_persist, bd_persist, A_disease_free, A_final and A_mean (adults averaged over the last 10 years).

source
Chytridiomycosis.ProbioticLoadProblem — Type
ProbioticLoadProblem(p::BriggsParameters, treatment; c, c_treated, h, N, ε = 0,
                     coverage = 0, treat_days = [0], days = 365)

Load tipping model for N frogs sharing a pool, starting uninfected, in which a treated frog has clearance c_treated instead of c. c and c_treated are one value for every frog or a vector with one value per frog, so frogs can differ in their defences. On each of treat_days every untreated frog is treated with probability coverage. Time in days (so treatment rates are per day).

solve(prob; rng) returns daily alive, treated and mean_load, and death_day for each frog (0 for survivors).

Chytridiomycosis.ProbioticAbundanceProblem — Type
ProbioticAbundanceProblem(p::BriggsParameters, treatment; c, c_treated, h, N, ε = 0,
                          coverage = 0, dose_days = [0], days = 365)

Load tipping model for N frogs sharing a pool, in which each frog carries its own abundance of the applied bacteria. A bath on each of dose_days sets the abundance of the bathed group (the first coverage × N frogs) to 1. Abundance declines with treatment.abundance_half_life and is exchanged between frogs at rate treatment.direct; clearance rises from c toward c_treated as B/(B + 1/treatment.protective_fold). c and c_treated are one value for every frog or a vector with one value per frog. Time in days. The other fields of treatment are not used.

solve returns daily t, alive, mean_load, abundance_bathed and abundance_unbathed (means over live frogs in each group), and death_day for each frog (0 for survivors).

source
Chytridiomycosis.ProbioticLarvalProblem — Type
ProbioticLarvalProblem(p::SchmidtParameters, stage::BsalLarvalStage, treatment;
    treat = :adults, coverage = 0, treat_times = [0.0], retention = 0, maternal = 0,
    t_intro = 0.0, I0 = 0.01, tspan = (0.0, 10.0))

Bsal with a larval stage (BsalLarvalProblem) and a treated class in both stages. At each of treat_times a fraction coverage of the untreated animals in treat (:adults, :larvae or :both) is treated. retention is the probability that a treated larva is still treated after metamorphosis; maternal the probability that a treated mother's larva is born treated. Bsal (I0 infectious adults per ha) arrives at t_intro. Time in years.

solve returns series t, adults, treated_adults, larvae, treated_larvae, infectious, and min_adults, mean_adults, final_adults (fractions of K, after t_intro), final_treated (treated fraction of adults) and final_prevalence.
