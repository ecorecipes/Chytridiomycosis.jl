Adaptive immunity and treatments (Woodhams et al. 2011)

This is a reference implementation of the models in the Appendix of Woodhams et al. (2011), Frontiers in Zoology 8:8 (doi:10.1186/1742-9994-8-8). The equations and values were read from the PMC full text (PMC3098159), including its Appendix "Mathematical Models" and the extended legend of Figure 6. The models are the Briggs et al. (2010) load model in three settings: one frog in a constant zoospore pool, the same frog with a hypothetical mucosal antibody, and a population of frogs sharing a dynamic pool. The paper calls the antibody model "purely speculative". Time is in days and loads are in sporangia per frog.

One frog in a constant pool

dS/dt = ν(A) γZ + ν(A) ηf S − σS,   ν(A) = p exp(−θA)
dA/dt = rS − cA

γZ is the paper's "γZ", the flux (γ/V)Z of zoospores encountering the frog, and ηf its "ηf". With no antibody (θ = 0) the load has the closed form S(t) = S0 e^{at} + b(e^{at} − 1)/a, with b = pγZ and a = pηf − σ.

With the Fig. 6B values the package reproduces the following:

  • The untreated frog reaches Smax = 10000 on day 32.2, "in 33 days".
  • Removing the frog from the pool on day 20 delays its death to day 36.9.
  • Lowering ν to 0.15 on day 20 makes a negative. The load then falls, but toward −b/a = 1500 sporangia, not to zero. The figure's curve agrees with this, but the legend says the frog "eventually clear[s] the infection" (target woodhams2011_fig6b_probiotic_clears, discrepant).
  • With both treatments together, the load decays to zero.
Figures 6C and 6D cannot be rebuilt

The paper does not print the antibody production rate r or the antibody decay rate c, and for Fig. 6D it does not print the zoospore death rate μ either. The keyed constructors therefore require these as keywords. The stable load of 916 sporangia in Fig. 6C depends only on r/c. With r/c = 0.01 the equilibrium is 917.4. Our inferred values r = 1e-4 and c = 0.01 reproduce the figure's curves, but they are not published, so the targets stay pending.

Typesetting slips in the paper
  • As rendered in PMC, the closed-form solution lacks its division by a.
  • The population equation has λ where it should have γ, and σS where it should have σS_i.
  • The legend of panel (d) writes "n" for ν.
Chytridiomycosis.ImmuneFrogParameters — Type
ImmuneFrogParameters(; p, γZ, ηf, σ, Smax, θ = 0, r = 0, c = 0)
ImmuneFrogParameters(:woodhams2011; set = "fig6b")
ImmuneFrogParameters(:woodhams2011; set = "fig6c", r, c)

One frog in a constant zoospore pool (Woodhams et al. 2011, Appendix), per day:

  • p: fraction of encounters that infect the frog with no antibodies (ν of the model without immunity);
  • γZ: zoospores from the pool encountering the frog, (γ/V)Z (zoospores day⁻¹);
  • ηf: zoospores per sporangium that immediately re-encounter the same frog (day⁻¹);
  • σ: sporangium loss rate (day⁻¹); Smax: lethal load (sporangia);
  • θ: fall of the infection fraction with antibody, ν(A) = p exp(−θA);
  • r, c: antibody production per sporangium and antibody decay (day⁻¹).

With θ = 0 (or r = 0) there is no adaptive immunity and the load follows the closed form constant_pool_load.

The keyed constructor reads the compendium. Set "fig6b" is the frog of Fig. 6B, without immunity. Set "fig6c" is the frog of Fig. 6C with immunity. The paper does not print r or c, so they must be given; no published values exist.

Load on a frog in a constant pool without adaptive immunity (Woodhams et al. 2011, Appendix): S(t) = S0 e^{at} + b(e^{at} − 1)/a, with b = p γZ and a = p ηf − σ (S0 + bt when a = 0). Throws when p has adaptive immunity.

Chytridiomycosis.constant_pool_equilibria — Function
constant_pool_equilibria(p::ImmuneFrogParameters; Smax_factor = 10) -> Vector{Float64}

Equilibrium loads of a frog in a constant pool, sorted.

  • Without adaptive immunity: [−b/a] when a = p ηf − σ < 0, otherwise empty (the load grows without bound).
  • With adaptive immunity (needs c > 0): the roots of p exp(−θ r S/c)(γZ + ηf S) = σS, found by bracketing on (0, Smax_factor·Smax]; the antibody level is A* = rS*/c. Fig. 6C reports 916 sporangia, but r and c are not printed (target woodhams2011_fig6c_stable_load is pending).

Chytridiomycosis.FrogTreatment — Type
FrogTreatment(time; γZ = nothing, p = nothing, S = nothing)

A treatment applied to a frog in a constant pool at time (days) (Woodhams et al. 2011, Fig. 6B, C). Each given field replaces the current value:

  • γZ: the encounter flux; γZ = 0 removes the frog from the zoospore pool;
  • p: the infection fraction with no antibodies, as after a probiotic-like constitutive defence (Fig. 6B(c): 0.15);
  • S: the load; S = 0 is an antifungal that clears the frog (Fig. 6C).

Chytridiomycosis.ConstantPoolFrogProblem — Type
ConstantPoolFrogProblem(p::ImmuneFrogParameters; S0 = 0, A0 = 0, tspan = (0.0, 60.0),
                        treatments = FrogTreatment[])

One frog in a constant zoospore pool, with or without adaptive immunity (Woodhams et al. 2011, Appendix; Fig. 6B, C), state [S, A]:

dS/dt = ν(A) γZ + ν(A) ηf S − σS,   ν(A) = p exp(−θA)
dA/dt = rS − cA

solve(prob) returns (sol, death_time). The frog dies, and the integration stops, when S reaches Smax; death_time is NaN for a frog that survives. treatments are applied at their times.

A population with a dynamic pool

dS_i/dt = ν(A_i) γ Z + ν(A_i) η f S_i − σ S_i
dA_i/dt = r S_i − c A_i
dZ/dt   = η(1 − f) Σ S_i − γ Z N − μ Z

Frog i dies when S_i reaches Smax. With θ = 0 this is the Briggs et al. (2010) model, and ImmunePopulationParameters(::BriggsParameters) converts between the two. In Fig. 6D the number of frogs is cut from 100 to 10 on day 30 (DensityReduction).

Chytridiomycosis.ImmunePopulationParameters — Type
ImmunePopulationParameters(; γ, η, f, σ, μ, Smax, p, θ = 0, r = 0, c = 0)
ImmunePopulationParameters(:woodhams2011; set = "fig6d", μ, r, c)
ImmunePopulationParameters(b::BriggsParameters; θ = 0, r = 0, c = 0)

Frogs sharing a dynamic zoospore pool, each with a load and an antibody level (Woodhams et al. 2011, Appendix, "Population-level model of infection with adaptive immunity"), per day:

  • γ: encounter rate between one zoospore and one frog, γ/V of the Briggs model;
  • η: zoospores released per sporangium; f: fraction that immediately re-encounter the same frog; σ: sporangium loss; μ: zoospore death in the pool; Smax: lethal load;
  • p, θ, r, c: as in ImmuneFrogParameters.

The keyed constructor reads the Fig. 6D values; μ, r and c are not printed and must be given. The third constructor turns a BriggsParameters into this form (γ = γ/V, p = ν); with θ = 0 the model is the Briggs et al. (2010) model.

Chytridiomycosis.ImmunePopulationProblem — Type
ImmunePopulationProblem(p::ImmunePopulationParameters; N, S0 = zeros(N), A0 = zeros(N),
                        Z0 = 0, tspan = (0.0, 100.0), reductions = DensityReduction[])

Woodhams et al. (2011) population model, state [S_1..S_N, A_1..A_N, Z]:

dS_i/dt = ν(A_i) γ Z + ν(A_i) η f S_i − σ S_i
dA_i/dt = r S_i − c A_i
dZ/dt   = η(1 − f) Σ S_i − γ Z N_alive − μ Z

Frog i dies when S_i reaches Smax. solve(prob) returns (sol, death_time, removal_time, alive); times are NaN for frogs that did not die or were not removed. With θ = 0 it reproduces BriggsLoadProblem.
