Published models

Reference implementations of published models, checked against the papers. Parameters are read from the compendium, for example SchmidtParameters(:schmidt2017).

Bsal in fire salamanders (Schmidt et al. 2017)

Chytridiomycosis.SchmidtParameters — Type
SchmidtParameters(; b, d, d_I, e, β, K, D = 0.0625, μ = 1.0)
SchmidtParameters(:schmidt2017)

Parameters of the Schmidt et al. (2017) model (eq. 2.1): recruitment b, natural death d, Bsal death d_I, latent→infectious rate e (all yr⁻¹), mass-action transmission β (ha yr⁻¹), carrying capacity K (females ha⁻¹), diffusion D (km² yr⁻¹) and scattered-colony rate μ (yr⁻¹). The density-dependence strength is γ = (b - d)/K.

source
Chytridiomycosis.SchmidtSLIProblem — Type
SchmidtSLIProblem(p; u0 = [K, 0, 0.01], tspan = (0.0, 1.0))

The temporal model (eq. 2.1). The default u0 is the paper's numerical experiment: a host population at K with one infectious individual per km² (0.01 ha⁻¹).

source
Chytridiomycosis.invasion_threshold — Function
invasion_threshold(p) -> K_threshold

Eq. (2.2): Bsal invades a host population at carrying capacity iff K > K_threshold, with K_threshold = (b + e)(b + d_I)/(β e).

source
Chytridiomycosis.removal_fraction — Function

Proportion of the host population to remove to prevent an outbreak: 1 - K_threshold/K.

source
Chytridiomycosis.basic_reproduction_number — Function
basic_reproduction_number(p) = K / K_threshold

R₀ of the linearised infected subsystem at the disease-free state S = K (derived here, not reported in the paper).

source
basic_reproduction_number(p::SchmidtParameters, s::BsalLarvalStage)

R₀ of Bsal with the larval stage: the largest eigenvalue of the next-generation matrix for the infected classes (infected larvae, latent adults, infectious adults) at the disease-free state. Carry-over through metamorphosis counts as a transition, not a new infection. With no larval transmission this is Schmidt's K / K_threshold.

source
Chytridiomycosis.endemic_equilibrium — Function
endemic_equilibrium(p) -> (S, L, I)

The non-trivial equilibrium of eq. (2.1), eq. (2.3) of the paper: I = (b - d)(Kβe - (b + e)(b + d_I)) / (β(Kβe - b(b - d))), L = (b + d_I - βI) I / e, S = (b + e - βI)(b + d_I - βI)/(βe). (The I² terms cancel in S + L + I = K_threshold - bI/e.) Returns nothing if K ≤ K_threshold.

source
Chytridiomycosis.hopf_threshold — Function
hopf_threshold(p; Kmax = 1000p.K) -> K_H

Carrying capacity at which the endemic equilibrium loses stability (Hopf bifurcation, with K as the bifurcation parameter), found by bisection. The paper reports K_H ≈ 9.5.

source
Chytridiomycosis.wave_speed — Function
wave_speed(p) -> c (km yr⁻¹)

Speed of the travelling wave of the reaction–diffusion model with equal diffusion D for all classes (eq. 2.4): c = 2√(Dλ), where λ = (√((e - d_I)² + 4eβK) - 2b - d_I - e)/2 is the growth rate of the linearised infected subsystem at S = K.

source
Chytridiomycosis.scattered_colony_area — Function
scattered_colony_area(p, t; c = wave_speed(p), μ = p.μ) -> km²

Eq. (2.5) as printed: total infected area A(t) = (2πc²/μ)((e^{μt} - 1)/μ - t). Note: the paper's reported proportions of German habitat (≈9% at μ = 1, ≈0.1% at μ = 0.1, after 8 years, of 258 750 km²) equal this value divided by 100; see the wiki page.

source
Chytridiomycosis.population_crash — Function
population_crash(p; tspan = (0, 2), dt = 1e-4) -> (Smin, tmin)

Minimum susceptible density and when it is reached (the paper's figure 1 summary).

source

Bd loads in frogs (Briggs et al. 2010)

Chytridiomycosis.BriggsParameters — Type
BriggsParameters(; V, γ, ν, f, μ, η, σ, Smax)
BriggsParameters(:briggs2010)

Pool volume V; zoospore–frog encounter rate γ (volume day⁻¹); establishment probability ν (so transmission is β = νγ); self-reinfection fraction f; zoospore death rate μ, zoospore release per sporangium η and sporangium loss σ (day⁻¹); lethal load Smax (sporangia).

source
Chytridiomycosis.BriggsLoadProblem — Type
BriggsLoadProblem(p; N, S0 = zeros(N), Z0 = 0.0, tspan = (0.0, 365.0))

Deterministic Briggs et al. (2010) model for N frogs with initial loads S0 and Z0 zoospores in the pool. Each frog dies (its load is removed and frozen at 0) when its load reaches Smax; solve returns (sol, death_time, alive), with death_time[i] = NaN for survivors.

source
Chytridiomycosis.transmission_rate — Function

Successful transmission rate from the pool, β = νγ.

source
Chytridiomycosis.load_growth_rate — Function
load_growth_rate(p, N)

Asymptotic per-day growth rate of Bd load on N identical frogs (the dominant eigenvalue of the linear system). Loads grow toward Smax when it is positive and decline toward clearance when it is negative.

source
Chytridiomycosis.host_density_threshold — Function
host_density_threshold(p) -> N*

Number of frogs per pool above which Bd load grows (det J = 0): N* = -aμ / ((aγ + νγη(1-f))/V), with a = ηνf - σ. Returns 0 when a ≥ 0 (loads grow from self-reinfection alone) and Inf when no density suffices.

source

With seasons and life stages

Chytridiomycosis.BriggsStage — Type
BriggsStage(; γ, ν, f, Smax, θ, lethal = true)

Stage-specific values: encounter rate γ, establishment probability ν, self-reinfection fraction f, load limit Smax, overwinter survival θ. If lethal, a host dies at Smax; otherwise its load is capped there.

source
Chytridiomycosis.BriggsSeasonalParameters — Type
BriggsSeasonalParameters(; V, μ, η, σ, adult, tadpole = nothing, R, K, θZ, m = 0.0,
                         εZ = 0.0, summer = 100.0)
BriggsSeasonalParameters(:briggs2010; set = "fig3b" | "fig3d" | "fig3f")

Parameters of the stochastic seasonal model. Without a tadpole stage, each frog leaves Poisson(R) recruits each spring, up to the ceiling K. With one, each adult leaves Poisson(R) tadpoles, and each tadpole metamorphoses with probability m per spring (losing its infection), up to K adults. εZ is the mean number of external zoospores added per day.

source
Chytridiomycosis.BriggsSeasonalProblem — Type
BriggsSeasonalProblem(p; years = 10, Δt = 1.0, poisson_below = 100.0, S0 = 10.0,
                      adults0 = p.K, tadpoles0 = round(Int, p.R * p.K), Z0 = 0.0)

Stochastic seasonal Briggs et al. (2010) model, started as in their Fig. 3: adults0 frogs of which one carries S0 sporangia, and Z0 zoospores. solve(prob; rng) returns a NamedTuple with per-year end-of-summer summaries (adults, tadpoles, infected_adults, mean_adult_load, Z, deaths) and persisted (frogs and Bd both present after the final winter).

source
Chytridiomycosis.persistence_probability — Function
persistence_probability(prob; nruns = 100, rng) -> fraction

Fraction of nruns runs in which hosts and Bd are both present at the end (the quantity mapped in Fig. 3 A, C and E of Briggs et al. 2010, for years = 10).

source

Bd in common toads at a pond (Mitchell et al. 2008)

Chytridiomycosis.MitchellParameters — Type
MitchellParameters(; t1, t2, ω, ι, ψ, ε, μP, μJ, μA, K, αP, ν, ρ, μZ, γ, φ)
MitchellParameters(:mitchell2008; set = "")

Parameters of the Mitchell et al. (2008) pond model, in years (t1, t2 as fractions of a year, ω in years). The compendium stores t1, t2 and ω in days; the keyed constructor divides them by 365.

source
Chytridiomycosis.MitchellPondProblem — Type
MitchellPondProblem(p; years = 35, spinup = 100, Z0 = 1e4, A0 = p.K / 2,
                    toad_limit = 50.0, bd_limit = 100.0)

Mitchell et al. (2008) model: run without Bd for spinup years from A0 adults, add Z0 zoospores at time 0, and run for years more. Toads are set to zero if adults fall below toad_limit, and Bd if zoospores fall below bd_limit.

solve(prob) returns a NamedTuple of series at every event time (t, PX, PY, J, A, Z, with values taken just after the event), toads_persist, bd_persist and A_disease_free (adults just before Bd is introduced).

source

Solving

Every problem is solved with solve (from CommonSolve.jl). Those that lower to one ODE can also be converted directly:

Chytridiomycosis.to_ode_problem — Function
to_ode_problem(prob)

The SciMLBase.ODEProblem that solve(prob) integrates, for the problems that lower to a single ODE: SchmidtSLIProblem, BriggsLoadProblem, LoadTippingProblem and BsalLarvalProblem. Use it to solve with other options or to pass the model to other SciML tools.
