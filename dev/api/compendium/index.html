Parameter compendium

Published parameter values are read from TOML files in data/compendium/, one per source paper. Each record has its units, a provenance code (M measured, F fitted, E elicited, A assumed, D derived), a role, the system it applies to, where in the paper it appears, and whether it has been checked against the paper (verified). Models take their published values only from here.

Chytridiomycosis.parameter_set — Function
parameter_set(key::Symbol; set = "") -> NamedTuple

The values for source paper key, keyed by symbol, in the units recorded in the compendium (each model documents the units it expects). Records without a set field form the base set; set = "fig3b" returns the base set with that named set's records added or substituted (for papers that use different values in different figures).
