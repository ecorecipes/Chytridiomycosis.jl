Load models

New models

These models are new work in this package, not published results.

Stochastic load on one host

A birth–death–immigration process for the number of sporangia on a host.

Chytridiomycosis.LoadBDI — Type
LoadBDI(ι, λ, σ)
LoadBDI(p::BriggsParameters; Z)

Birth–death–immigration process for the sporangial load on one host: immigration ι (sporangia day⁻¹), per-sporangium self-reinfection λ and loss σ (day⁻¹).

source
Chytridiomycosis.load_distribution — Function
load_distribution(m::LoadBDI, t = Inf) -> NegativeBinomial

Distribution of sporangia on a host that was uninfected at time 0, after t days at constant exposure. t = Inf is the enzootic stationary distribution (λ < σ). For λ > σ the mean grows without bound while the shape k stays at ι/λ.

Chytridiomycosis.mean_load — Function

Mean sporangia per host at time t (the Briggs equation's solution from S(0) = 0).

source
Chytridiomycosis.prevalence — Function

Probability that a host carries at least one sporangium at time t.

source
Chytridiomycosis.aggregation — Function
aggregation(m::LoadBDI) -> k = ι/λ

Negative-binomial shape of the load distribution: infection from the pool relative to self-reinfection. It does not change with time, with host density or with swab efficiency.

source
Chytridiomycosis.infection_gain_rate — Function

Rate (day⁻¹) at which an uninfected host becomes infected: ι.

source
Chytridiomycosis.infection_loss_rate — Function
infection_loss_rate(m::LoadBDI)

Stationary rate (day⁻¹) at which an infected host returns to zero load. By detailed balance it is ι π₀ / (1 − π₀), with π₀ the uninfected fraction.

source
Chytridiomycosis.enzootic_pool — Function
enzootic_pool(p::BriggsParameters; N, ε) -> Z*

Equilibrium zoospore pool when N hosts at their mean stationary load share a pool that also receives ε zoospores per day from outside (a reservoir, tadpoles or another host species). It is finite only below the host-density threshold host_density_threshold(p), and diverges as N approaches it.

source
Chytridiomycosis.enzootic_load_distribution — Function
enzootic_load_distribution(p::BriggsParameters; N, ε) -> NegativeBinomial

Stationary distribution of sporangia per host for N hosts below the density threshold, kept infected by an external zoospore input ε (day⁻¹).

source
Chytridiomycosis.swab — Function
swab(d::NegativeBinomial, ρ) -> NegativeBinomial

Distribution of the count on a swab that recovers each sporangium independently with probability ρ. The shape k is unchanged, so k can be estimated without knowing ρ.

Load tipping

The Briggs load model with saturating clearance by the host, which gives a low-load state and collective tipping when enough hosts share a pool.

Chytridiomycosis.LoadTipping — Type
LoadTipping(; ι, λ, σ, c, h, κ = 0)
LoadTipping(p::BriggsParameters; c, h, Z)        # one host, pool fixed at Z
LoadTipping(p::BriggsParameters; c, h, N, ε = 0) # N hosts, pool at quasi-steady state

Sporangial load with saturating clearance, dS/dt = ι + (λ − σ + κ) S − c S/(h + S). c (sporangia day⁻¹) and h (sporangia) are new parameters with no published values. κ is the pool feedback from N identical hosts (see pool_feedback); it is zero for a single host in a fixed pool.

source
Chytridiomycosis.LoadTippingProblem — Type
LoadTippingProblem(p::BriggsParameters; c, h, N, ε = 0, S0 = zeros(N), Z0 = nothing,
                   tspan = (0.0, 365.0))

N hosts with loads S0 sharing a zoospore pool that also receives ε zoospores per day. Each host follows the Briggs equation plus clearance c S/(h + S), and dies when its load reaches p.Smax. c and h are either one value for all hosts or a vector with one value per host (hosts that differ in their defences). Z0 defaults to the pool's quasi-steady state for S0. solve returns (sol, death_time, alive), as for BriggsLoadProblem.

source
Chytridiomycosis.LoadTippingRecruitmentProblem — Type
LoadTippingRecruitmentProblem(p::BriggsParameters; c_median, sdlog, h, K, ε = 0,
    heritability = 0, recruits = 0.5, survival = 0.9, years = 50, season = 365.0,
    N0 = K)

The load tipping model over years years with host turnover. N0 founders have clearance c drawn from LogNormal(log(c_median), sdlog); each year the loads run for season days, then hosts survive with probability survival and each leaves Poisson(recruits) recruits, up to K hosts. A recruit's c is inherited from one parent with parent–offspring regression heritability (on the log scale).

solve(prob; rng) returns per-year vectors hosts (at the start of the year), deaths (from Bd), median_c (at the start of the year) and mean_load (survivors, end of season), and the final c of each host.

source
Chytridiomycosis.pool_feedback — Function
pool_feedback(p::BriggsParameters, N) -> κ

Per-sporangium growth rate (day⁻¹) that N identical hosts gain through the shared pool, κ = νγη(1−f)N / (V(μ + γN/V)). The Briggs threshold N* is where κ = σ − ηνf.

source
Chytridiomycosis.net_growth_rate — Function

Net per-sporangium growth rate at high load, R = λ − σ + κ (day⁻¹).

source
Chytridiomycosis.critical_immigration — Function
critical_immigration(m::LoadTipping) -> ι_crit

Infection rate from the pool above which no low-load state exists: (√c − √(R h))² for 0 ≤ R < c/h, 0 for R ≥ c/h, and Inf for R < 0 (loads never run away).

source
Chytridiomycosis.tipping_regime — Function
tipping_regime(m::LoadTipping) -> :stable, :bistable or :runaway

:stable: one stable load and no runaway (R ≤ 0). :bistable: a stable low load and an unstable threshold above which load runs away. :runaway: no low-load state.

source
Chytridiomycosis.load_equilibria — Function
load_equilibria(m::LoadTipping) -> (low, threshold)

The stable low load and the unstable threshold load (sporangia per host): the roots of R S² + (ι + R h − c) S + ι h = 0. In the :stable regime threshold = Inf; in the :runaway regime both are NaN.

source
Chytridiomycosis.pooled_load_equilibria — Function
pooled_load_equilibria(p::BriggsParameters; c, h, ε = 0, N = length(c))
    -> (regime, ι_low, low, ι_threshold, threshold)

Equilibria of N hosts that differ in their clearance parameters (c, h: a value or a vector per host) and share one pool. Each host's load is set by the infection rate from the pool, ι, and the pool closes the loop: ι = ι₀ + (κ/N) Σᵢ Sᵢ(ι). low and threshold are vectors of per-host loads at the stable low state and at the unstable threshold state (empty when that state does not exist); regime is as in tipping_regime. Needs ηνf < σ (no host runs away on its own). Found by a scan and bisection on ι.

source
Chytridiomycosis.critical_host_number — Function
critical_host_number(p::BriggsParameters; c, h, ε = 0) -> N

Smallest number of identical hosts per pool at which the low-load state is lost (the fold). It is at or above the Briggs threshold host_density_threshold(p), and Inf if clearance holds at every density. Found by a scan and bisection on N.

source
Chytridiomycosis.mean_time_to_runaway — Function
mean_time_to_runaway(m::LoadTipping; Smax, from = 0) -> days

Mean time for the stochastic load of one host (pool fixed, κ = 0) to first reach Smax sporangia, starting from from. Exact for the birth–death chain, by the recursion τ(n) = 1/b(n) + d(n)/b(n) τ(n−1) for the mean time from n to n + 1. Inf when ι = 0 (the load can be lost for good). Its inverse is a hazard of death.

source
Chytridiomycosis.low_state_distribution — Function
low_state_distribution(m::LoadTipping; nmax) -> DiscreteNonParametric

Approximate distribution of sporangia on a host in the low-load state (pool fixed, κ = 0): the stationary distribution of the birth–death chain confined to 0:nmax. nmax defaults to the unstable threshold in the :bistable regime and must be given otherwise. It is a good approximation while runaway is rare. With c = 0 it is the negative binomial of LoadBDI.

Stochastic frog loads

Chytridiomycosis.StochasticFrogProblem — Type
StochasticFrogProblem(p::BriggsParameters, treatment = MicrobiomeTreatment(); c,
    c_treated = c, h, N, ε = 0, coverage = 0, dose_days = [0], days = 365, dt = 0.05)

c_treated is likewise one value or a vector; by default it equals c (no effect).

Stochastic load tipping model for N frogs sharing a pool: whole sporangia and zoospores, steps of dt days. c is one value or a vector (frogs that differ). On each of dose_days the bathed group (the first coverage × N frogs) gets bacterial abundance 1, which raises its clearance toward c_treated as described for ProbioticAbundanceProblem, using treatment.abundance_half_life, treatment.protective_fold, treatment.direct (exchange) and treatment.half_life (random loss of all bacteria). With the defaults the bacteria last for life.

solve(prob; rng) returns daily t, alive and mean_load (over live frogs), and death_day for each frog (0 for survivors).
