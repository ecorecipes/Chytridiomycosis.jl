Bsal transmission functions (Malagon 2020, Tompros 2022)

Is transmission of Batrachochytrium salamandrivorans (Bsal) density-dependent or frequency-dependent? The answer decides whether thinning a population can stop an outbreak. Two experiments on adult eastern newts (Notophthalmus viridescens) bear on it:

  • Malagon et al. (2020), Sci Rep 10:5584 (doi:10.1038/s41598-020-62351-x), counted contacts between uninfected newts at three densities. They fitted a saturating (Holling type II) contact function and put it in an SEI model of a cohabitation experiment.
  • Tompros et al. (2022), Transbound Emerg Dis 69:731–741 (doi:10.1111/tbed.14043), followed epidemics in twenty 1-m² tanks with 2 to 32 newts. They fitted eight transmission functions and found that frequency dependence fits best.

This page gives the transmission functions as reusable types, the two experiments' models, and refits of both analyses to the authors' data. Equations and values were checked against the published articles, Malagon's Supplementary Information and Tompros's appendix. The data are the authors' deposits: Malagon's Supplementary File 2 (data/malagon2020) and the Tompros TRACE deposit (doi:10.7290/xw8yy2RBeu; data/tompros2022).

Reproduction

These are reproductions of published analyses, not new models. What reproduces and what does not is recorded in the validation targets (sources malagon2020 and tompros2022).

Transmission functions

A transmission function gives φ(S, I, N), the total rate of new infections when S susceptible and I infectious hosts are in a population of N. Tompros et al. write it as φ = α S I / N, where α is the per capita contact rate times the probability that a contact infects. Frequency dependence keeps α constant. Density dependence makes it grow with N. The saturating forms fall between the two.

Chytridiomycosis.TransmissionFunction — Type
TransmissionFunction

Abstract type of a transmission function. A subtype gives the total rate of new infections φ(S, I, N) (per unit time) through infection_rate. S and I are the numbers (or densities) of susceptible and infectious hosts, and N is the population size that enters the contact rate, which is S + I unless the model has other classes.

The subtypes are the eight candidates of Tompros et al. (2022, Table 2) and the Holling type II contact function of Malagon et al. (2020):

typeφ(S, I, N)
DensityDependentβ S I
FrequencyDependentβ S I / N
PowerLawβ Sᵃ Iᵇ
QuadraticSaturationS I / (κ₀ + κ₁ N + κ₂ N²)
StructuralSaturationS I / (κ₀ + κ_S S + κ_I I + κ₂ S I)
PrevalenceDependentβ x y
PrevalencePowerLawβ xᵃ yᵇ
PrevalenceSaturationx y / (κ₀ + κ₁ x + κ₂ x²)
HollingContactβ c S I / (K + N)

with x = S/N and y = I/N. Use one as the transmission term of an SLI model with TransmissionSLIProblem, of the mesocosm master equation with SusceptibleChainProblem, or of the cohabitation experiment with CohabitationProblem.

source
Chytridiomycosis.DensityDependent — Type
DensityDependent(β)

Density-dependent (mass-action) transmission, φ = β S I. The per capita contact rate α = β N grows with population size. β has units time⁻¹ host⁻¹ (or time⁻¹ area host⁻¹ when S and I are densities). This is the transmission term of SchmidtSLIProblem.

source
Chytridiomycosis.FrequencyDependent — Type
FrequencyDependent(β)

Frequency-dependent transmission, φ = β S I / N. The per capita contact rate α = β does not change with population size. β has units time⁻¹. Tompros et al. (2022) select this form, with β = 0.230 day⁻¹ (see TomprosParameters).

source
Chytridiomycosis.PowerLaw — Type
PowerLaw(β, a, b)

Power-law transmission, φ = β Sᵃ Iᵇ (Tompros et al. 2022, appendix eq. 7). It is phenomenological. With a = b = 1 it is DensityDependent. The exponents are dimensionless, and β has units time⁻¹.

source
Chytridiomycosis.QuadraticSaturation — Type
QuadraticSaturation(κ₀, κ₁, κ₂)

"Quadratic saturation" of Tompros et al. (2022, appendix eq. 4): α = N / (κ₀ + κ₁ N + κ₂ N²), so φ = S I / (κ₀ + κ₁ N + κ₂ N²). With κ₁ = κ₂ = 0 it is density-dependent (β = 1/κ₀); with κ₀ = κ₂ = 0 it is frequency-dependent (β = 1/κ₁); with only κ₂ = 0 it is a Holling type II contact rate. The κ's have units of time (time × host for κ₀, time / host for κ₂).

source
Chytridiomycosis.StructuralSaturation — Type
StructuralSaturation(κ₀, κ_S, κ_I, κ₂)

"Structural saturation" of Tompros et al. (2022, appendix eq. 5): saturation depends on the numbers of susceptible and infected hosts separately, φ = S I / (κ₀ + κ_S S + κ_I I + κ₂ S I). It equals QuadraticSaturation(κ₀, κ_S, 0) when κ_S = κ_I and κ₂ = 0.

source
Chytridiomycosis.PrevalenceDependent — Type
PrevalenceDependent(β)

"Simple prevalence" transmission of Tompros et al. (2022), φ = β x y with x = S/N and y = I/N. The total infection rate does not grow with population size. β has units time⁻¹.

source
Chytridiomycosis.PrevalencePowerLaw — Type
PrevalencePowerLaw(β, a, b)

Power law in the prevalences, φ = β xᵃ yᵇ (Tompros et al. 2022, appendix eq. 8).

source
Chytridiomycosis.PrevalenceSaturation — Type
PrevalenceSaturation(κ₀, κ₁, κ₂)

Quadratic saturation in the prevalence of susceptibles (Tompros et al. 2022, appendix eq. 6): α = (1/N) / (κ₀ + κ₁ x + κ₂ x²), so φ = x y / (κ₀ + κ₁ x + κ₂ x²). With κ₁ = κ₂ = 0 it is PrevalenceDependent with β = 1/κ₀.

source
Chytridiomycosis.HollingContact — Type
HollingContact(β, c, K)
HollingContact(p::MalagonParameters)

The transmission term of Malagon et al. (2020): a Holling type II contact rate per host, f(N) = c N / (K + N), times the probability β that a contact with an infectious host transmits, times the frequency term S I / N:

φ = β f(N) S I / N = β c S I / (K + N)

c is the asymptotic number of contacts per host per unit time, K the half-saturation population (hosts, or hosts per m² in the paper) and β a probability. In the paper c is in contacts newt⁻¹ day⁻¹ (Supplementary Table S1: 2153.29 without plants, 587.31 with plants) although the text calls f a rate per hour; see MalagonParameters.

Chytridiomycosis.transmission_coefficient — Function
transmission_coefficient(tf::TransmissionFunction, N) -> Float64

Rate at which one infectious host infects others in an otherwise susceptible population of size N: ∂φ/∂I at S = N, I = 0. Divided by the rate at which infectious hosts are removed it gives R₀ (basic_reproduction_number). It is β for FrequencyDependent, β N for DensityDependent, β c N/(K + N) for HollingContact and N/(κ₀ + κ₁ N + κ₂ N²) for QuadraticSaturation. It is infinite for the power laws with b < 1.

source

basic_reproduction_number has a method for a transmission function: the coefficient divided by the rate at which infectious hosts are removed.

In a Schmidt-style S–L–I model

Any of these can replace the mass-action term of the fire salamander model of Schmidt et al. (2017). With DensityDependent(p.β) the result is the published model. The newt estimates are per newt per 1-m² tank per day, so they do not transfer to that model's units (adult females per hectare per year) without a scaling argument, which is not made here.

Chytridiomycosis.TransmissionSLIProblem — Type
TransmissionSLIProblem(p::SchmidtParameters, tf::TransmissionFunction;
                       u0 = [p.K, 0, 0.01], tspan = (0.0, 1.0))

The S–L–I model of Schmidt et al. (2017, eq. 2.1) with its mass-action term β S I replaced by φ(S, I, N) of the transmission function tf, where N = S + L + I:

dS/dt = (b − d) S − γ S N − φ(S, I, N)
dL/dt = φ(S, I, N) − (d + e) L − γ L N
dI/dt = e L − (d + d_I) I − γ I N

p.β is not used. Time is in years and densities in adult females per hectare, so the parameters of tf must use the same units (for example FrequencyDependent(β) with β in yr⁻¹). With tf = DensityDependent(p.β) the problem is the same as SchmidtSLIProblem. The transmission functions of the newt studies were fitted to newts in 1-m² tanks over days; their values are not on the scale of this model and are not transferred to it here.

source

Tompros et al. (2022): eight candidate functions

In each tank, death and recovery are ignored over the first five days. The number of susceptibles then falls by one at rate φ(S, N − S, N), and its probability distribution follows the master equation (appendix eq. 2):

dp_S/dt = φ(S+1, N−S−1, N) p_{S+1} − φ(S, N−S, N) p_S

The likelihood multiplies, for each tank and each interval between swab days (0, 2 and 5), the probability of the observed number of susceptibles given the numbers at the start of the interval.

Chytridiomycosis.SusceptibleChainProblem — Type
SusceptibleChainProblem(tf::TransmissionFunction, S0, I0; tspan = (0.0, 5.0))

The probabilistic transmission model of Tompros et al. (2022, appendix eq. 2). A closed population of N = S0 + I0 hosts has no deaths or recoveries. The number of susceptibles S falls by one at rate φ(S, N − S, N). The probabilities p_S(t), S = 0, …, S0, follow

dp_S/dt = φ(S+1, N−S−1, N) p_{S+1} − φ(S, N−S, N) p_S,     p_{S0}(0) = 1.

solve(prob) integrates this linear ODE and returns the ODESolution of the vector [p_0, p_1, …, p_{S0}]. susceptible_distribution gives the same probabilities at one time from the matrix exponential, which is what the likelihood uses. The time unit is that of tf (days for Tompros et al.).

source
Chytridiomycosis.susceptible_distribution — Function
susceptible_distribution(tf::TransmissionFunction, S0, I0, t; method = :auto)
    -> Vector{Float64}

Probabilities [p_0(t), …, p_{S0}(t)] of the number of susceptibles after time t in a closed population that starts with S0 susceptible and I0 infected hosts (SusceptibleChainProblem).

  • method = :uniformization sums the uniformized chain, Σₖ Poisson(k; q t) Pᵏ e, with q the largest rate and P = I + A/q. Every term is non-negative, so small probabilities keep their relative accuracy. The series is cut where the Poisson tail is below 10⁻¹⁶.
  • method = :exp applies the matrix exponential exp(A t) of the generator A.
  • method = :auto (default) uses uniformization when q t ≤ 500 and the matrix exponential otherwise.

The two agree to about 10⁻¹²; the authors integrated the master equation with lsoda.

The refit reproduces the ranking and the estimates of Table 2, including β = 0.230 day⁻¹ and its interval [0.181, 0.293]. It also reproduces the hold-out "AIC" of section 3.3 (65.9 and 70.6) and the paper's R₀ = 4.9. It also rebuilds the authors' processed counts from the raw swab results, using their false-negative and false-positive rules.

Differences from the paper
  • Density dependence. The paper says its fit failed to converge. Here it has a finite maximum (β = 0.0117 newt⁻¹ day⁻¹) that is 28.5 AIC units worse than frequency dependence. That supports the paper's conclusion.
  • κ₀ of quadratic saturation. The refit gives 0.0227, against 0.026 printed. κ₀ is barely identified (Fig. 4 puts 95% of its profile in [0, 34.2]); κ₁, κ₂ and the NLL agree.
  • Mortality. The paper reports 45% total mortality. The deposit gives 42.9% of the newts exposed by contact and 53.8% of all newts.
  • The interval for β is the central 95% of the normalised likelihood, a credible interval under a flat prior on the grid, not a likelihood-ratio interval.

Chytridiomycosis.clean_infection_series — Function
clean_infection_series(positive, necropsy) -> Vector{Bool}

The decision rules of Tompros et al. (2022, section 2.3), as in the authors' CodeFile1_PreProcess.R, for one newt's swab series in time order (necropsy marks a swab taken at death):

  1. a single negative between two positives is a false negative, and so is a negative necropsy straight after a positive swab;
  2. then a single positive between two negatives is a false positive, and so is a positive necropsy straight after a negative swab.

Each rule is applied to the whole series at once (vectorised), as in the R code.

Malagon et al. (2020): contacts and cohabitation

Experiment 1 filmed newts at 2, 4 and 8 per m², with and without plants. The contact rate per newt was fitted to

f(N) = c N / (K + N)

using the three densities plus a fourth point from the cohabitation containers, which held 2 newts in 0.015 m² (about 133 m⁻²). In Experiment 2 an infected newt was housed with a susceptible one for 1 second, 10 minutes or 30 minutes. The SEI model of that experiment is

dS/dt = −β c S I_c / (K + N)
dE/dt =  β c S I_c / (K + N) − γ E
dI/dt =  γ E − d I

where the infected newts I_c are present only during the cohabitation. β (the probability that a contact transmits) and γ (the rate of becoming qPCR-positive) were chosen on a grid to match the cumulative proportion of newts positive at days 6, 12, 18 and 24.

The refit reproduces:

  • the means behind Fig. 1;
  • the four ANOVA F statistics;
  • c and K of Supplementary Table S1 (2153.29 and 79.55 without plants, 587.31 and 52.78 with plants);
  • all twelve γ and sums of squares of Table S1, and eleven of its twelve β;
  • the statements about Fig. 6;
  • R₀ = 1.9 for complex habitat.
What the R₀ of Malagon et al. measures
  • Fig. 6 is not a population. The caption describes a population after one infected newt arrives. The authors' code instead simulates the cohabitation experiment: 66.5 infected and 66.5 susceptible newts per m², together for 10 minutes. There is no transmission afterwards.
  • R₀ is not an epidemic R₀. R₀ = −ln(1 − z)/z is applied to the cumulative proportion infected. For plants, the curve's asymptote (0.761) gives 1.9. Without plants, the asymptote is 0.988, which gives 4.5. The paper's 0.95, which gives 3.2, is the value at about one month.
  • Neither number is the R₀ of an epidemic in a newt population. With the fitted contact rate and d as the removal rate, β c N/(K + N)/d is about 5.7 × 10⁴ at 133 newts m⁻² (derived here, not published).
  • Units and other slips. Table S1's c is per day, although the text says per hour. The code's bounds on c and K are the reverse of the printed ones. In the table's row "Plants In, day 18, 10 min", β is printed as 0.93, but the grid minimum is at 0.98, which matches the printed sum of squares.
Chytridiomycosis.MalagonParameters — Type
MalagonParameters(; β, c, K, γ, d)
MalagonParameters(:malagon2020; habitat = :simple, disease_state = 12, cohabitation = 10,
                  mortality = :published)

Parameters of the SEI model of Malagon et al. (2020), in days:

  • β: probability that a contact with an infected newt transmits Bsal (dimensionless);
  • c: asymptotic contact rate, contacts newt⁻¹ day⁻¹;
  • K: half-saturation density, newts m⁻²;
  • γ: rate from exposed to infectious (qPCR-positive twice), day⁻¹;
  • d: disease-induced death rate, day⁻¹.

The keyed constructor reads the compendium. habitat is :simple (no plants) or :complex (nine artificial plants per m²), which sets c and K; disease_state (12, 18 or 24 days since the infected newt was exposed) and cohabitation (10 or 30 minutes) pick the row of Supplementary Table S1 for β and γ. The paper's Fig. 6 uses day 12 and 10 minutes.

mortality = :published uses the death rate printed in the supplement, d = −ln(0.8)/10 = 0.0223 day⁻¹. mortality = :code uses d = 1/42.75 day⁻¹, the value in the authors' MATLAB code (SEIParameterStructure4.m).

Units of c. The paper defines f(N) = cN/(K + N) as contacts per newt per hour and constrains 0 ≤ c ≤ 100. The values in Table S1 (2153.29 and 587.31) are per day: the authors' code fits the hourly rate and multiplies it by 24. The code's bounds are c ≤ 1.8 × 10⁵ (hourly) and K ≤ 100, the reverse of the bounds printed in the paper.

Chytridiomycosis.CohabitationProblem — Type
CohabitationProblem(p::MalagonParameters; N = 133, introduced = N/2,
                    duration = 10/1440, tspan = (0.0, 100.0),
                    transmission = HollingContact(p))

The SEI model of Malagon et al. (2020, Methods and Supplementary Information) for their Experiment 2, in days. Infected newts (introduced) are housed with susceptible newts for duration days (10 minutes by default) and then removed:

dS/dt = −φ(S, I_c(t), N(t))
dE/dt =  φ(S, I_c(t), N(t)) − γ E
dI/dt =  γ E − d I

with I_c(t) = introduced for t < duration and 0 afterwards, and N = S + E + I + I_c. The default transmission is φ = β c S I_c / (K + N) (HollingContact). The state is [S, E, I, C, D], where C (cumulative newts that became infectious, ∫γE) and D (cumulative deaths, ∫dI) are what the paper plots, as C/S(0) and D/S(0).

The defaults follow the authors' code (SolveSEImodel6.m, SEImodel4.m): the experiment held 2 newts in 0.015 m², which they scaled to N = 133 newts m⁻² with half of them infected. The printed equations multiply by the infectious class I, but the code uses the introduced newts I_c and adds them to N. The two agree only if I includes the introduced newts, because new infections cannot become infectious within 10 minutes.

solve(prob) integrates the model with the removal time duration as a tstop and returns the ODESolution; cohabitation_curve gives the same curves in closed form.

What Fig. 6 shows. The paper describes Fig. 6 as a simulated population after the introduction of one infected newt. The code instead simulates this cohabitation experiment, with 66.5 infected newts per 66.5 susceptibles for 10 minutes, and no transmission afterwards.

Chytridiomycosis.cohabitation_curve — Function
cohabitation_curve(prob::CohabitationProblem, t) -> (; infectious, dead)

Closed-form cumulative proportions C(t)/S(0) (became infectious) and D(t)/S(0) (died) of the cohabitation model, for a time or a vector of times. During the cohabitation the population N is treated as constant; it changes only through deaths, which are of order 10⁻⁶ of N in 10 minutes. The result agrees with solve(prob) to about 10⁻⁶. The grid search of fit_cohabitation uses this form.

Chytridiomycosis.final_size_reproduction_number — Function
final_size_reproduction_number(z) -> Float64

R₀ from the final proportion infected z through the final-size relation of a closed SIR epidemic, 1 − z = exp(−R₀ z) (Anderson & May 1991, eq. 6.21): R₀ = −ln(1 − z)/z. Malagon et al. (2020) apply it to the cumulative proportions infected that they read from their Fig. 6 (0.95 without plants, 0.77 with plants) to get R₀ = 3.2 and 1.9.

Chytridiomycosis.load_malagon2020 — Function
load_malagon2020() -> (; contacts, swabs, fit_inputs, survival)

The data of Malagon et al. (2020):

  • contacts: one NamedTuple per video hour of Experiment 1, with density (newts per 1-m² pool), habitat (:simple without plants, :complex with plants), day, diel (1–4), pool and contacts (contacts in the hour); 672 rows;
  • swabs: one row per Experiment 2 treatment and swab day, with disease_state (days since the infected newt was exposed: 12, 18, 24), cohabitation (minutes: 10, 30), day and proportion (cumulative proportion of the five susceptible newts positive on two swabs);

Chytridiomycosis.fit_contact_function — Function
fit_contact_function(density, total; Kmax = 100) -> (; c_hour, c, K, ssr)

Least-squares fit of the Holling type II contact function f(N) = c N / (K + N) to the per capita contacts total ./ density (contacts per newt per hour), as in the authors' NonLinFit.m and objfun.m, with 0 ≤ K ≤ Kmax (the code's bound; the paper prints the bounds of c and K the other way round). For each K the best c is linear, so the fit is a one-dimensional search over K. Returns the hourly c_hour, c = 24 c_hour (contacts newt⁻¹ day⁻¹, as in Supplementary Table S1), K (newts m⁻²) and the sum of squared residuals ssr (contacts² newt⁻² h⁻²).

Chytridiomycosis.fit_cohabitation — Function
fit_cohabitation(c, K, observed; days = [6, 12, 18, 24], β = 0:0.01:0.98,
                 γ = 0:0.01:2, N = 133, duration = 10/1440, interpolate = true)
    -> (; β, γ, ssr, grid)

Grid search of Malagon et al. (2020, Supplementary Information; SolveSEImodel6.m) for the transmission probability β and the latency rate γ (day⁻¹). For each pair it computes the cumulative proportion infectious C(t)/S(0) of the CohabitationProblem with contact parameters c (contacts newt⁻¹ day⁻¹) and K, and sums the squared differences from observed at days. The pair with the smallest sum is returned, with the matrix grid of sums (rows γ, columns β); ties go to the smallest β, then the smallest γ.

With interpolate = true the model is sampled on range(0, 100; length = 100) and interpolated linearly to days, as the authors' code does with interp1.
