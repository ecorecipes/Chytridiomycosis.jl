Bayesian fit to field data

New analysis

The load equation, its priors and these posteriors are new work in this package, not a published analysis. The data are from Knapp et al. (2022), CC BY 4.0.

The maximum likelihood fit of Fitting to field data gives point estimates, AIC and profile likelihoods. The Bayesian fit puts a weakly informative prior on every parameter of a KnappLoadModel, samples the posterior with NUTS and compares mechanisms by their leave-one-out predictive accuracy (PSIS-LOO).

  • KnappPosterior adds the prior to the likelihood. It implements the LogDensityProblems interface on the log parameters.
  • turing_model turns it into a Turing.jl model. It is defined in the package extension ChytridiomycosisTuringExt, loaded by using Turing. The likelihood uses a fixed-step integrator, so it is differentiable and NUTS can use ForwardDiff gradients.
  • pointwise_loglikelihood gives one log-likelihood per swab and draw. psis_loo, waic and elpd_difference compare mechanisms with it.
using Chytridiomycosis
using Turing: Turing, NUTS, MCMCThreads, sample, InitFromParams

m = KnappLoadModel(:applied)
post = KnappPosterior(m)                         # default prior: knapp_prior(m)
x0 = Chytridiomycosis.maximum_likelihood(m).x    # Turing also exports maximum_likelihood
chn = sample(turing_model(post), NUTS(1000, 0.99), MCMCThreads(), 1000, 4;
    initial_params = fill(InitFromParams((; x = x0)), 4))
X = reshape(Array(chn), :, length(x0))           # draws × log parameters
loo = psis_loo(pointwise_loglikelihood(m, X))

Priors

Each parameter has a lognormal prior on its natural scale, so its logarithm, which the sampler works with, has a normal prior. The medians are orders of magnitude that are plausible before seeing the swabs. The spreads cover several orders of magnitude for the rates, loads and J. lividum levels, and a factor of about 20 either way for half-lives and standard deviations. The within-frog rate r0 = ηνf − σ = −0.156 per day stays fixed at the Briggs et al. (2010) compendium value, as in the maximum likelihood fit, so that the two fits stay comparable. Untreated frogs sit at equilibrium and fix only ι/(−r0). The rate of return itself would be informed only by the treated frogs, whose return is also shaped by the extra clearance, so a free r0 would trade off against Δc, h and τ or K. The table is in the docstring of knapp_prior.

Results

The run below is scripts/knapp_bayes.jl: 4 chains of 1000 draws after 1000 adaptation steps, started near the maximum likelihood estimate with jitter (standard deviation 0.3 on the log scale), on 4 threads. Target acceptance was 0.99 for applied, which had 16 divergent transitions at 0.9, and 0.9 for the others.

What the posterior adds to the maximum likelihood fit:

  • h is weakly, not un-, identified. It lies along a ridge with Δc (correlation of the logs 0.86 for decay, 0.91 for applied). The data fix the low-load clearance rate Δc/h, and they rule out h below a few hundred copies. The posterior standard deviation of log h is 0.30 (decay) and 0.45 (applied) of the prior's, so the prior still shapes its upper tail.
  • K is below a few genomic equivalents. P(K < 1) = 0.85 and P(K < 3) = 0.99. The lower end of the interval is near the prior's 2.5% point, so the data set only an upper bound.
  • τ is bounded on both sides, 18–108 days, narrower above than the profile interval (about 17–200 days). P(τ > 56 days, the length of the trial) = 0.24.
  • Treated frogs' median load under applied: 1.9 × 10³ (980–3.3 × 10³) on day 12, 2.7 × 10³ (1.5–5.0 × 10³) on day 37 and 1.0 × 10⁵ (3.3 × 10⁴ – 2.4 × 10⁵) on day 56.
  • The mechanisms are not separable. ΔAIC of 6.2 reads as a clear preference. The LOO difference, 2.9 ± 2.7, shows it is about one standard error.

Swabs are treated as independent, as in the maximum likelihood fit, so all of these intervals are too narrow if swabs from the same frogs are correlated.

API

Chytridiomycosis.KnappPosterior — Type
KnappPosterior(m::KnappLoadModel; prior = knapp_prior(m))

Posterior of the log parameters of m (in the order of parameter_names) under prior, a NamedTuple of LogNormal distributions on the natural scale of each parameter. It implements the LogDensityProblems interface: the log density at log parameters x is the log prior density of x (normal, Normal(μ, s) for LogNormal(μ, s)) plus LogDensityProblems.logdensity(m, x). Sample it with NUTS through turing_model (using Turing), and compare mechanisms with pointwise_loglikelihood and psis_loo.

Chytridiomycosis.turing_model — Function
turing_model(post::KnappPosterior)

The posterior post as a Turing.jl model: the log parameters x (a vector in the order of parameter_names) get the normal prior of post, and the log-likelihood of the swabs is added with @addlogprob!. Its log joint at x equals LogDensityProblems.logdensity(post, x). Requires using Turing. The likelihood is differentiable (a fixed-step integrator), so NUTS with ForwardDiff works:

using Turing
chn = sample(turing_model(post), NUTS(0.8), MCMCThreads(), 1000, 4)
X = Array(chn)      # draws × parameters, log scale

Chytridiomycosis.observed_swabs — Function
observed_swabs(m::KnappLoadModel)

Indices into m.swabs of the swabs that enter the likelihood, in the order of pointwise_loglikelihood: those taken on day −7, 0, 12, 37 or 56 with a Bd load, or with a J. lividum count after the first bath.

source
Chytridiomycosis.pointwise_loglikelihood — Function
pointwise_loglikelihood(m::KnappLoadModel, x::AbstractVector) -> Vector
pointwise_loglikelihood(m::KnappLoadModel, X::AbstractMatrix) -> Matrix

Log-likelihood of each swab that enters the fit (Bd and J. lividum together), at log parameters x, in the order of observed_swabs. The sum is LogDensityProblems.logdensity(m, x). Every entry is -Inf where the model cannot be evaluated. For a matrix X of draws (one draw of the log parameters per row) the result has one row per draw and one column per swab, as psis_loo and waic take it.

source
Chytridiomycosis.psis_loo — Function
psis_loo(ll::AbstractMatrix) -> NamedTuple

Leave-one-out cross-validation by Pareto smoothed importance sampling (Vehtari, Gelman & Gabry 2017), from a matrix of pointwise log-likelihoods with one row per posterior draw and one column per observation (as from pointwise_loglikelihood). Returns elpd (the expected log predictive density, summed over observations), its standard error se, the effective number of parameters p and, per observation, pointwise (elpd) and k (the Pareto shape: estimates are reliable when k < 0.7). Draws from several chains can be stacked; the tail length assumes a relative efficiency of 1.

source
Chytridiomycosis.waic — Function
waic(ll::AbstractMatrix) -> NamedTuple

Widely applicable information criterion (Watanabe 2010) on the elpd scale, from pointwise log-likelihoods (one row per draw, one column per observation): elpd, its standard error se, the effective number of parameters p (summed posterior variances of the pointwise log-likelihood) and pointwise. −2 elpd is WAIC on the deviance scale.

source
Chytridiomycosis.elpd_difference — Function
elpd_difference(a, b) -> NamedTuple

Difference in expected log predictive density a.elpd − b.elpd between two results of psis_loo or waic on the same observations, with the standard error of the difference from the paired pointwise values (se = √(n var(a_i − b_i))). A positive difference favours a.
