Outbreak-state HMM (Wilber 2022)

Wilber, Knapp, Smith and Briggs (2022, Journal of Animal Ecology 91:2451–2464, 10.1111/1365-2656.13823) asked whether host density shapes what happens after Bd reaches a Rana sierrae/R. muscosa population, at three branch points: whether Bd invades, how far the population declines, and how heavily frogs become infected. They used 79 to 111 lakes of the Sierra Nevada surveyed from 2004 to 2019. The implementation here follows the accepted manuscript and the authors' code and data (Zenodo 10.5281/zenodo.7114634). Appendices S1–S4 were not obtained. The deposit has no open licence, so it is not bundled; see data/wilber2022/README.md and wilber2022_path.

Hidden Markov models

A small, model-agnostic layer: scaled forward and backward recursions, smoothed state probabilities, Viterbi paths, covariate-dependent transition matrices, categorical emissions and a LogDensityProblems wrapper for several independent sequences sharing parameters. Emission "likelihoods" are a T×K matrix, so an observation model need not be a normalised distribution (Wilber 2022's is not). The tests check every function against brute-force enumeration of all paths.

Chytridiomycosis.hmm_forward — Function
hmm_forward(initial, transitions, likelihoods; emit_first = true) -> NamedTuple

Scaled forward recursion of a hidden Markov model with K states and T steps. initial is the state distribution at the first step; transitions is one K×K row-stochastic matrix or a vector of T − 1 of them (the t-th gives Pr(X_{t+1} = j | X_t = i) in row i, column j); likelihoods is the T×K matrix of emission likelihoods p(y_t | X_t = k), with a row of ones for a missing observation.

The filtered vector is renormalised at every step and the log normalising constants are summed, so the log-likelihood does not underflow for long sequences. With emit_first = false the first row of likelihoods is not used: the first observation only fixes the start (the convention of the Wilber et al. 2022 Stan code, which starts every population in a known state).

Returns loglik, filtered (T×K, row t is Pr(X_t | y_1:t)) and logc (the log normalising constant of each step; sum(logc) == loglik). A zero-probability sequence gives loglik = -Inf and NaN filtered rows from that step on.

Log-likelihood of one observed sequence: hmm_forward(…).loglik.

Chytridiomycosis.hmm_backward — Function
hmm_backward(transitions, likelihoods, logc) -> Matrix

Scaled backward recursion matching hmm_forward: with logc the forward log normalising constants, row t of the result is β_t(k) = p(y_{t+1:T} | X_t = k) divided by exp(sum(logc[t+1:T])), so filtered .* backward gives smoothed probabilities.

hmm_posterior(initial, transitions, likelihoods; emit_first = true) -> Matrix

Chytridiomycosis.CovariateTransitions — Type
CovariateTransitions(f, covariates)

Covariate-dependent transition matrices: f(θ, x) returns the K×K row-stochastic matrix for parameters θ and one covariate row x, and covariates holds one row per transition (T − 1 rows; row t drives the step from t to t + 1). Call it as ct(θ) to get the vector of matrices for hmm_forward.

source
Chytridiomycosis.HMMLogDensity — Type
HMMLogDensity(sequences, logprior, dimension; emit_first = true)

A LogDensityProblems target for a set of independent HMM sequences that share parameters. sequences(θ) returns an iterable of (initial, transitions, likelihoods) tuples (or named tuples with those fields), one per sequence; logprior(θ) is the log prior density on the same (unconstrained) parameter vector. logdensity is the prior plus the sum of the hmm_loglikelihoods; pointwise_loglikelihood returns one value per sequence.

Hypothesis 1: failed and successful invasion

Each lake is in one of four states each June: U (Bd-free), LP (Bd at prevalence at most ρ), HP (above ρ) or E (extirpated). Rows are the state in year t, columns in t + 1 (Fig. 2A):

\[P = \begin{pmatrix} 1-a & a\omega & a(1-\omega) & 0\\ \varphi & \omega(1-\varphi) & (1-\omega)(1-\varphi) & 0\\ 0 & 0 & 1-e & e\\ 0 & 0 & 0 & 1 \end{pmatrix}, \qquad \operatorname{probit}(\cdot) = \beta_0 + \beta_1 D_t + \beta_2 T_t + \beta_3 S_{t+1} + \beta_4 \mathrm{Tad}_t + \beta_5 T_t S_{t+1}\]

for ω and φ (eqn 1), with D the z-scored log10(count + 1) of adults and subadults, T the z-scored mean June–September maximum air temperature, S the z-scored 1 April snow water equivalent of the following spring, and Tad tadpole presence. φ large means failed invasions; ω large means Bd stays at low prevalence. Where the count is missing, φ and ω are averaged over D ~ Normal(filled value, σ). Observed states are classified from the swabs (y positives of n), and the emission weights account for sampling error (wilber2022_emission).

Differences between the printed text and the authors' code (the code is followed, with keywords for two quirks):

  • eqn 1 prints log10(D); the code uses log10(D + 1), with D the larger of the count and the number swabbed;
  • every lake starts in U in 2004 and the 2004 observation is not used;
  • the emission weights are not normalised over observations;
  • the LP/HP split of swab counts is n ÷ ⌊1/ρ⌋ (cutoff_rule = :exact uses ⌊nρ⌋);
  • the adult + subadult count is treated as missing when all subadult entries are missing (subadult_rule = :sum fixes this).

The posterior is sampled by adaptive random-walk Metropolis (the package has no MCMC dependency; the model has 13–15 parameters and a cheap likelihood). Leave-one-out uses psis_loo with one observation per lake, as the authors did.

fit = wilber2022_fit(cutoff = 0.25)                 # full model, abundance, cached
posterior_summary(fit)                              # medians and 95% intervals
wilber2022_effect(fit, :phi_temperature)            # Fig. 3: positive, interval above zero
looic(wilber2022_fit(cutoff = 0.25, model = :linear_temp)) - looic(fit)   # Table 1: 2.30

PSIS-LOO over 79 lakes has a Monte Carlo error of 0.2–0.8 LOOIC units per run (a lake or two with Pareto k near 0.7), so scripts/wilber2022_looic.jl stores four-seed means in data/wilber2022/looic.toml; the Table 1 targets use those.

Reproduced (validation targets wilber2022_*): all ten Fig. 3 effect sizes of the abundance model at the three cutoffs (nine within 0.03, the long-tailed φ-tadpole within 0.15), the LOOIC values behind Table 1 (absolute values within 0.8 of the authors', differences within 2.0), and the headline: abundance has a weak effect on ω in the direction opposite to the density-threshold prediction and none on φ, while warm summers raise φ (less so before severe winters) and tadpoles lower it. The density models of Table 1 are not reproducible because the lake areas are not in the deposit.

Chytridiomycosis.Wilber2022Data — Type
Wilber2022Data

The data of the outbreak-state HMM of Wilber et al. (2022) for one prevalence cutoff ρ, built by wilber2022_data exactly as the authors' prepare_stan_data. One row per lake (sites, sorted), one column per year 2004–2019 (years). Fields:

  • obs: observed state, -1 missing, 0 U (no Bd detected), 1 LP (prevalence ≤ ρ), 2 HP, 3 E (no frogs counted or swabbed; only as the last observation);
  • sample_size, num_inf: frogs swabbed and Bd-positive (-1 for no survey);
  • abundance: z-scored log10(count + 1) (adults + subadults, or the number swabbed if larger; gaps filled); temperature: z-scored mean June–September maximum air temperature (°C, gridMET); snow: z-scored 1 April snow water equivalent (mm, CDEC); tadpole: presence (0/1, 0.5 if unknown) or z-scored log10(tadpoles + 1);
  • missing_abundance: true where the visual-encounter count is missing;
  • likelihoods: lake × year × state emission weights (see wilber2022_emission);
  • scaling: means and sds used to z-score abundance (on log10(count + 1)), temperature (°C) and snow (mm);
  • cutoff, cutoff_rule, tadpole_covariate.

Chytridiomycosis.wilber2022_data — Function
wilber2022_data(; cutoff = 0.25, tadpole = :presence, include_subadults = true,
                subadult_rule = :code, cutoff_rule = :code, path = wilber2022_path())
    -> Wilber2022Data

Build the Hypothesis 1 data set of Wilber et al. (2022) from the authors' deposit (wilber2022_path): 79 lakes, 2004–2019. cutoff is the prevalence ρ between the low- and high-prevalence states (the paper uses 0.25, 0.3333 and 0.5). tadpole = :presence (the full model) or :log_abundance (Table 1, "replace tadpoles p/a with log10 tadpoles"). subadult_rule = :sum and cutoff_rule = :exact replace two coding quirks of the original (see Wilber2022Data and the source notes); the defaults reproduce the paper.

Chytridiomycosis.wilber2022_emission — Function
wilber2022_emission(obs, n, y, cutoff; cutoff_rule = :code) -> NTuple{4,Float64}

Emission weights (U, LP, HP, E) of one lake-year in the Wilber et al. (2022) code (transformed data Pmat): obs is the observed state code (-1 missing, 0 U, 1 LP, 2 HP, 3 E), n frogs swabbed, y positive. Missing gives (1, 1, 1, 1); obs U gives (1, I(0, ρ), I(ρ, 1), 0) with I(a, b) = ∫_a^b (1 − p)^n dp; obs LP or HP gives (0, S(0, ρ), S(ρ, 1), 0), where S(a, b) integrates the probability that a binomial count of n lands in the observed class against the Beta(y + 1, n − y + 1) density of prevalence over [a, b]; obs E gives (0, 0, 0, 1). The LP class is 1 ≤ K ≤ n ÷ ⌊1/ρ⌋ (cutoff_rule = :code) or 1 ≤ K ≤ ⌊nρ⌋ (:exact). The weights are not normalised over observations, as in the original.

Chytridiomycosis.OutbreakHMMProblem — Type
OutbreakHMMProblem(data::Wilber2022Data; model = :full)
OutbreakHMMProblem(; cutoff = 0.25, model = :full, kwargs...)

The outbreak-state hidden Markov model of Wilber et al. (2022) (Hypothesis 1: failed and successful Bd invasion), as a LogDensityProblems target on the unconstrained parameter vector (names in prob.names):

  • logit_a, logit_ext: Bd arrival (U → LP or HP) and extirpation (HP → E) per year;
  • omega_*, phi_*: probit coefficients of ω (stay in LP rather than move to HP; also the LP share of arrivals) and φ (LP → U, a failed invasion) on the z-scored covariates of Wilber2022Data;
  • log_sigma_abundance: log sd of the abundance covariate where the count is missing.

model is :full (eqn 1: abundance, temperature, winter severity, tadpole presence, temperature × winter severity), :log_tadpole (log10 tadpole abundance instead of presence), :linear_temp (no winter severity) or :quadratic_temp (no winter severity; temperature and temperature²), the four models of Table 1. Priors are those of the Stan code: intercepts and logit_a, logit_ext Normal(0, 5), slopes Normal(0, 3), σ half-Cauchy(0, 2) (with the log-Jacobian). The keyword form builds the data with wilber2022_data (with tadpole = :log_abundance for :log_tadpole).

solve(prob; chains = 4, warmup = 5000, iterations = 12_000, thin = 4, rng) samples the posterior by adaptive random-walk Metropolis (Haario et al. 2001; no MCMC library is a dependency) and returns an OutbreakHMMFit with 12 000 draws by default.

Hypothesis 2: magnitude of decline

A beta-binomial regression of the decline from the maximum to the minimum count on the z-scored log10 of the maximum count (or density), for lakes where Bd prevalence peaked between the two (eqn 2; 82 lakes counting subadults, 52 adults only).

Chytridiomycosis.Wilber2022DeclineProblem — Type
Wilber2022DeclineProblem(; subadults = true, covariate = :abundance,
                         path = wilber2022_path())

The beta-binomial regression of Hypothesis 2 of Wilber et al. (2022) (eqn 2): lakes where the maximum count came before the minimum and Bd prevalence peaked (≥ 0.25) in between, minus the seven lakes the authors excluded (82 lakes with subadults, 52 adults only). The decline n_max − n_min ~ BetaBinomial(n_max, pφ, (1 − p)φ), logit p = β0 + β1 z, z the z-scored log10 of the maximum count (covariate = :abundance) or count per metre of shoreline (:density). Parameters [β0, β1, log φ]; priors as in the Stan code (β0 flat, β1 ~ Normal(0, 5), φ ~ half-Cauchy(0, 2)). Fields start, stop, z, mean, sd (of the log10 covariate), sites. solve(prob; chains = 4, warmup = 4000, iterations = 40_000, thin = 10, rng) samples the posterior by adaptive random-walk Metropolis from the Laplace mode (Wilber2022DeclineFit).
