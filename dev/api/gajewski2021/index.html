Bd growth in varying temperatures (Gajewski 2021)

This is a reference implementation of the model of Gajewski et al. (2021), Ecol Evol 11:17920–17931 (doi:10.1002/ece3.8379): the optical density (OD) of a Bd culture follows a logistic curve with a delay, whose growth rate is a thermal performance curve (TPC). The authors fitted five TPCs to Stevenson et al.'s (2013) constant-temperature data, and used each fit to predict growth under three fluctuating regimes. Equations and values were checked against the full text, Appendix S1, and the authors' code (Zenodo doi:10.5281/zenodo.4525954).

Model

Time in days, temperature T in °C:

Y(t) = Y0                                          t < d     (Eq. 1)
     = K Y0 / (Y0 + (K − Y0) exp(−r(T)(t − d)))    t ≥ d
dx/dt = r(T(t)) x (1 − x/K) 1(t > d),  x(0) = Y0             (Eq. 3)

The five curves are Briere (Brière-2), Ratkowsky, SharpeSchoolfieldIkemoto, Logan10 and Stinner, in the forms of the authors' code.

Differences between the paper and the code
  • Likelihood. The paper prints a lognormal likelihood for every fit. The code uses it for Brière-2 and Ratkowsky only, and a normal truncated at zero for Ikemoto, Logan-10 and Stinner. GajewskiModel follows the code by default (likelihood = :as_coded); with the data, −2 log L at the posterior mode plus 2k matches the penalized deviances of Table 1 to within 8 units for all five fits. The ΔDIC of Table 1, which favours Stinner, therefore compares deviances of different likelihoods.
  • Ikemoto delay. The Ikemoto JAGS model uses exp(d) as the delay; Table 2 prints d (0.007), and the predictions use d. See ikemoto_delay in GajewskiParameters.
  • Kelvin. The fits use T + 273.15, the predictions T + 273.16, and the last segment of the Wet Low Frog regime omits the offset, so the kelvin-based curves see 25 K there (as_coded in gajewski_prediction).
  • Logan-10 α. Appendix S1 prints its median as 0.134, outside its own HDI (0.885, 0.957); with the data the posterior mode is 0.914. Targets built on the printed α are discrepant.
  • Table B.1. The logistic fits without a TPC to each regime are not reproduced from the deposited data: the mode of the authors' model is far from the printed medians.

The summaries of the curve at the printed posterior medians (gajewski_summary) reproduce Table 1 (adjusted limits, maximum r), Table 2 (optima) and Table B.2 (median rate in each regime) to 0.2 °C and 1 %; they are not the posterior medians of the summaries that the paper reports, so the agreement is approximate except for Stinner, whose optimum is a parameter.

Chytridiomycosis.Stinner — Type
Stinner(; C, k1, k2, Topt)

The Stinner et al. (1974) curve, as coded by Gajewski et al. (2021): C / (1 + exp(k1 + k2 T)) for T < Topt and C / (1 + exp(k1 + k2 (2Topt − T))) from Topt up. With k2 < 0 it rises to a plateau near C and is symmetric about Topt. It never reaches zero.

source
Chytridiomycosis.Logan10 — Type
Logan10(; α, c, b, Tmax, ΔT)

The Logan-10 curve (Logan et al. 1976), as coded by Gajewski et al. (2021): α (1/(1 + c exp(−b T)) − exp(−(Tmax − T)/ΔT)) for T < Tmax, and zero from Tmax up. Just below Tmax it is negative; the code does not clip it, and neither does this curve.

source
Chytridiomycosis.SharpeSchoolfieldIkemoto — Type
SharpeSchoolfieldIkemoto(; ρ, TΦ, ΔHA, ΔHL, TL, ΔHH, TH, R = 1.987,
                         kelvin_offset = 273.15)

The Sharpe–Schoolfield–Ikemoto curve (Ikemoto 2005), as coded by Gajewski et al. (2021):

r(T) = ρ (T/TΦ) exp(ΔHA/R (1/TΦ − 1/T)) /
       (1 + exp(ΔHL/R (1/TL − 1/T)) + exp(ΔHH/R (1/TH − 1/T)))

with T in kelvin, the enthalpies ΔHA, ΔHL < 0, ΔHH in cal mol⁻¹, R in cal K⁻¹ mol⁻¹, and TΦ the intrinsic optimum temperature (K). It is called with T in °C, converted by adding kelvin_offset. Unlike SharpeSchoolfield it has the factor T/TΦ, from Eyring's rate theory.

Chytridiomycosis.delayed_logistic — Function
delayed_logistic(t, Y0, K, r, d = 0)

The logistic curve with a delay (Gajewski et al. 2021, Eq. 1; Voyles et al. 2017): Y0 for t < d, then K Y0 / (Y0 + (K − Y0) exp(−r (t − d))). With d = 0 it is the standard logistic curve that Sheets et al. (2021) fit to normalised MTT readings.

Chytridiomycosis.gajewski_curve — Function
gajewski_curve(form, θ; kelvin_offset = 273.15) -> ThermalPerformanceCurve

The thermal performance curve form of Gajewski et al. (2021) with parameters θ (any property collection, such as a NamedTuple or the compendium set of that form), called with temperature in °C:

formCurveParameters
:briere2Briere, m = bc, Tmin, Tmax, b (°C)
:ratkowskyRatkowskyc, k, Tmin, Tmax (kelvin)
:ikemotoSharpeSchoolfieldIkemotoρ, TΦ, ΔHA, ΔHL, TL, ΔHH, TH (K, cal mol⁻¹), R
:logan10Logan10α, c, b, Tmax, ΔT (°C)
:stinnerStinnerC, k1, k2, Topt (°C)

The kelvin temperatures of Ratkowsky and Ikemoto are converted with kelvin_offset: 273.15 in the authors' fits and 273.16 in their predictions.

Chytridiomycosis.GajewskiParameters — Type
GajewskiParameters(; form, Y0, K, d, tpc)
GajewskiParameters(:gajewski2021; form = :stinner, kelvin_offset = 273.15,
                   ikemoto_delay = :printed, α = nothing)

The delayed logistic growth of Bd optical density with a temperature-dependent rate (Gajewski et al. 2021, Eqs 1 and 3), for one of the five TPC fits form (see gajewski_curve):

  • Y0: initial optical density;
  • K: maximum optical density;
  • d: delay before growth (days);
  • tpc: the growth rate r(T) (day⁻¹, T in °C), an IsolateTPC.

The keyed constructor reads the posterior medians of that fit from the compendium (Appendix S1 Tables B.3–B.7, Table 2). The medians of the parameters do not give the posterior median curve, so summaries of the curve built from them (its optimum, peak, adjusted limits) only approximate the paper's Table 1 and 2 values.

  • kelvin_offset: 273.15 (the fits) or 273.16 (the authors' predictions), for Ratkowsky and Ikemoto.
  • ikemoto_delay: :printed uses d = 0.007 as in Table 2 and Predictions.R; :fit uses exp(d), the delay in the authors' JAGS model for the Ikemoto fit.
  • α: replaces the Logan-10 α, whose printed median (0.134) contradicts its own HDI (0.885, 0.957).

Chytridiomycosis.GajewskiRegime — Type
GajewskiRegime(name; as_coded_kelvin = false)

One of the three varying-temperature regimes of Gajewski et al. (2021), :DLA (Dry Low Air), :WHF (Wet High Frog) or :WLF (Wet Low Frog): the authors' piecewise-linear fit to the incubator logger (functions.R), repeated every day. Callable as T(t), t in days, T in °C. The segments are read from the compendium (sets "regime_<name>").

With as_coded_kelvin = true, the last segment of :WLF (from 0.861 d) returns 25 − 273.16 °C, which is what the authors' code feeds the kelvin-based curves (Ratkowsky and Ikemoto) there: it omits the offset in that segment, so they see 25 K.

source
Chytridiomycosis.GajewskiGrowthProblem — Type
GajewskiGrowthProblem(p::GajewskiParameters; temperature, tspan = (0.0, 14.0))

Logistic growth of optical density under a time-varying temperature (Gajewski et al. 2021, Eq. 3), in days:

dx/dt = r(T(t)) x (1 − x/K) 1(t > d),   x(0) = Y0

temperature is a number (°C, constant) or any callable T(t), such as a GajewskiRegime or a SeasonalTemperature. solve(prob) returns the ODESolution; to_ode_problem gives the ODEProblem. At constant temperature the solution is delayed_logistic (Eq. 1).

source
Chytridiomycosis.gajewski_prediction — Function
gajewski_prediction(form, regime; as_coded = true, tspan = (0.0, 14.0), kwargs...)

The optical density predicted by the posterior medians of TPC fit form under varying regime regime (:DLA, :WHF or :WLF), as in Gajewski et al. (2021) Fig. 4 but at the medians rather than over posterior draws. Returns the ODESolution of GajewskiGrowthProblem.

With as_coded = true (the default), the kelvin-based curves use the offset 273.16 and the :WLF regime keeps the authors' slip in its last segment (GajewskiRegime), as in Predictions.R. With as_coded = false the offset is 273.15 and the slip is removed. Other keywords go to GajewskiParameters (ikemoto_delay, α); solver tolerances are reltol = abstol = 1e-8.

Chytridiomycosis.regime_growth_rate — Function
regime_growth_rate(p::GajewskiParameters, regime; step = 1e-3, mass = 0.95)
    -> (median, lo, hi)

The logistic growth rate r(T(t)) over one day of a varying regime (a GajewskiRegime or any callable T(t)): its median and its mass highest density interval over a grid of step days on [0, 1). Gajewski et al. (2021) report this summary in Appendix S1 Table B.2; they do not say how it was computed, and this is our reading of it.

source
Chytridiomycosis.adjusted_limits — Function
adjusted_limits(c; threshold = 0.01, range = (-10.0, 50.0), step = 0.01) -> (lo, hi)

The adjusted thermal limits of Gajewski et al. (2021): the lowest and highest temperatures (°C) on a grid of step over range at which the curve c exceeds threshold. Their code takes the grid point next to the first and last values above the threshold (Predictions.R); this returns the crossing found by bisection instead.

source
Chytridiomycosis.gajewski_summary — Function
gajewski_summary(form; as_coded = true, kwargs...) -> NamedTuple

The curve summaries of Gajewski et al. (2021) Tables 1, 2 and B.2, computed from the curve at the posterior medians of fit form (GajewskiParameters; keywords go to it): Topt and r_max (thermal_optimum on 0–45 °C), Tmin_adj and Tmax_adj (adjusted_limits), and r_DLA, r_WHF, r_WLF, the median rates over each regime (regime_growth_rate). With as_coded = true the regime rates of the kelvin-based curves use the authors' prediction offset (273.16) and the :WLF slip, as in gajewski_prediction. The paper's values are posterior medians of each summary, which the summary of the median curve only approximates.

Data and posterior

Data not bundled

The Zenodo release has no licence, so its data are not bundled. gajewski2021_path finds them in the lab workspace or in ENV["CHYTRIDIOMYCOSIS_GAJEWSKI2021"]. The constant-temperature data are Stevenson et al.'s (2013) experiment, not an independent one. Validation targets that need the data are recorded as pending; test/gajewski2021.jl runs them when the data are present.

scripts/gajewski2021_mcmc.jl samples the posterior of each fit by random-walk Metropolis from its mode.

Chytridiomycosis.gajewski2021_path — Function
gajewski2021_path() -> String

Folder with the data of Gajewski et al. (2021) (optical_QLD.csv, Vary_OD.csv): the authors' Zenodo release 10.5281/zenodo.4525954, extracted. It is not bundled (the release has no licence file). The path is ENV["CHYTRIDIOMYCOSIS_GAJEWSKI2021"] if set, else papers/gajewski2021/zenodo/gzach93-Predict_Bd_Growth_VaryEnvir-c4ade0e under the first ancestor of the package directory that has it. Throws an ArgumentError if neither exists.

Chytridiomycosis.GajewskiModel — Type
GajewskiModel(; form = :stinner, likelihood = :as_coded, data = load_gajewski2021().constant)

The posterior of one hierarchical fit of Gajewski et al. (2021): Eq. 1 for every constant-temperature well, with r given by TPC form (see gajewski_curve) and one Y0, K and d shared by all temperatures.

  • likelihood = :as_coded follows the authors' JAGS models: lognormal for :briere2 and :ratkowsky, normal truncated at zero for :ikemoto, :logan10 and :stinner, and the delay exp(d) for :ikemoto. The paper (Methods 2.5) prints a lognormal likelihood for all five; likelihood = :lognormal gives that, with the delay d.
  • Priors are the authors' (compendium sets "prior" and "prior_<form>").

Parameters are on their natural scale, in the order of parameter_names: Y0, K, d, σ, then the curve's own. The model implements the LogDensityProblems interface; the log density is the log posterior up to a constant (-Inf outside the prior support). Use posterior_mode for its mode and scripts/gajewski2021_mcmc.jl to sample it.

source
Chytridiomycosis.GajewskiLogisticModel — Type
GajewskiLogisticModel(regime; data = load_gajewski2021().varying)

The logistic model (Eq. 1) without a TPC, fitted by Gajewski et al. (2021) to each varying-temperature regime (Methods 2.7; Appendix S1 Table B.1; the authors' jags-logistic.bug): Y_i ~ Normal(μ_i, σ), not truncated, with priors r ~ Gamma(1, 1), K ~ Uniform(0.08, 0.2) (compendium set "prior_logistic") and the Y0, d and σ priors of the hierarchical fits. Parameters Y0, K, d, r, σ on their natural scale. Implements the LogDensityProblems interface (the log posterior up to a constant).

Chytridiomycosis.gajewski_start — Function
gajewski_start(m::GajewskiModel) -> Vector{Float64}

A starting point for posterior_mode or a sampler: the printed posterior medians of the fit (compendium set "<form>"), with two exceptions. The Logan-10 α starts at the midpoint of its printed HDI, because the printed median is inconsistent with it; and σ, which the paper does not report, is the root mean square residual at that point on the scale of the likelihood. For :ikemoto with the as-coded likelihood, d is the printed value, which the code exponentiates.

source
gajewski_start(m::GajewskiLogisticModel)

The printed posterior medians of Table B.1 for the regime, with σ the root mean square residual there.

source
Chytridiomycosis.posterior_mode — Method
posterior_mode(m; x0 = gajewski_start(m), rounds = 3, iters = 4000)

The mode of the log posterior of a GajewskiModel or GajewskiLogisticModel, by Nelder–Mead from x0 in coordinates scaled by max(|x0|, 1e-3), restarted rounds times from the best point with a smaller simplex. With thousands of readings the mode is close to the posterior medians that the paper reports. Returns a NamedTuple with model, x, estimates (by name) and logdensity.
