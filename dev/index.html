Chytridiomycosis

Reference implementations of models of amphibian chytridiomycosis (Batrachochytrium dendrobatidis, Bd, and B. salamandrivorans, Bsal), with a parameter compendium that records units and provenance. Plans and verification notes: the OKF wiki in ../../wiki.

source

Models of amphibian chytridiomycosis, caused by the fungi Batrachochytrium dendrobatidis (Bd) and B. salamandrivorans (Bsal), built on SciML. The package contains reference implementations of published models, a parameter compendium that records where every published value comes from, and new models of treating amphibians with protective skin bacteria.

Published and new work

The models under Published models reproduce their papers. Everything else is new work in this package and is not a published result. Apart from values read from the compendium, the parameters of the new models are illustrative.

Getting started

using Chytridiomycosis
p = SchmidtParameters(:schmidt2017)      # values from the compendium
basic_reproduction_number(p)             # 24.8
sol = solve(SchmidtSLIProblem(p))        # an ODE solution

Every problem is a struct describing the model and its set-up, solved with solve. Most return a named tuple of time series and summaries; see each problem's documentation.

Tutorials

  • Building biological realism: for three systems, the treatment model is built from the simplest model one piece of biology at a time, ending with chance.
  • One model, many switches: a single nested model in which every combination of biology is compared like for like, and a stochastic version.
  • Fitting to a field trial: the frog load equation fitted to field swabs of treated, wild and control frogs, comparing four explanations for why treated frogs stayed low.

The tutorials are Quarto documents in vignettes/, rendered to HTML, PDF and Markdown.
